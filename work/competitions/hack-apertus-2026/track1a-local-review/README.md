# Hack Apertus 2026 / Track 1A — local evidence review

This is a **public, offline-only evidence viewer** for the released *Apertus 1A five-issue evidence kit* (shared internal Commons Library `/Commons/competitions/HackApertus2026/hack_apertus_track1a_five_issue_evidence_20261009.zip`; immutable original source SHA-256 `cae2f02e9f40fa96620f653a4652d45253999e9888f6775fbc6bca3602bee6c9`).

## What works

1. Open `index.html` in a modern browser or serve the directory with `python3 -m http.server 8765` and visit `http://localhost:8765`. Uses browser Web Crypto SHA-256; refuses verification if unavailable.
2. Select the *actual*, **privately captured** `results.jsonl` generated by that kit's `runner.py --live`. Optionally select a separately prepared human reviewer `review.jsonl`; both remain in-browser.
3. Click **Verify and review**. The viewer checks exact text SHA-256 for each captured response and prompt, known case IDs/languages/model names, source/request hashes, duplicates, timestamps, and the conditions under which a review can reference a successful capture.
4. Inspect the five category cards. The default display shows hash references, model, language, and review state; raw model text is concealed in a second disclosure. **Export redacted summary** writes only local status, hashes, timestamps, and reviewer-declared decision; no raw prompts, responses or reviewer free-text notes are included.

This viewer makes **zero API requests** and uses no libraries, analytics, data persistence or external scripts. It is not a model harness, not the competition submission interface, and cannot authenticate a human review or establish that a model output is actually incorrect. `REVIEWER_DECLARED_CONFIRMED_LOCAL` means only that an imported reviewer file makes that claim with minimally complete fields and matching captured languages. It never means the organizer confirmed a bug, accepted an entry, or paid a prize.

## Input file contracts

`results.jsonl`: schema-1 line records from the released companion runner, up to 50 lines / 2 MiB. Only `de`, `fr`, `it`, the five catalog case IDs, and named Apertus v1.5 8B or 70B are admitted. The viewer checks `prompt_sha256` for **all** provider attempts and `response_sha256` for successful `status:"captured"` responses; HTTP/transport errors remain errors. Missing hashes or malformed records fail closed. The raw local file stays under operator control.

`review.jsonl` (optional): at most 10 records, one per case, decision `confirmed` / `not_confirmed` / `needs_review`. A confirmed declaration requires substantial `reviewer`, `analysis`, `reproduction`, `risk` strings and `affected_languages` with at least one successfully captured language.

Keep the model-capture JSONL private until an authorized human has checked personal data, quoted copyrighted material, official sources and the contest license. Even a matching SHA-256 only proves the captured bytes have not changed relative to the digest *in that file*; it does not authenticate the provider or independent assessment. Do not use the local summary as a cash or prize receipt.
