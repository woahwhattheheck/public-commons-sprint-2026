# Original Apex operator journey

This runs one complete operator workflow on the retained Town of Apex workspace and its original source editions. The existing fleet runtime owner admits it after the FSU receiving continuation.

## Run

The installed browser and Playwright runtime are reused:

```sh
/opt/codex/runtimes/codex-primary-runtime/dependencies/node/bin/node \
  /workspace/scratch/f11d76a9f6d6/apex-compensation-20261012/operator-journey/apex-operator-journey.mjs
```

`APEX_BROWSER_SCRATCH` may point to the original runtime owner's allocated browser directory. `APEX_OPERATOR_OUTPUT`, `APEX_WORKBENCH_APP`, `APEX_OPERATOR_WORKSPACE`, `APEX_BROWSER_EXECUTABLE` and `APEX_PLAYWRIGHT_MODULE` can retain the same mounted originals on another equipped process. The original workspace ID, exact source IDs and accepted output hashes are fixed in `original-case.json`.

The committed source lives at `staff-market-workbench/examples/apex-operator-journey`. To run that copy against the retained original case, set the source, workspace and accepted-export root explicitly:

```sh
APEX_OPERATOR_ROOT=/workspace/scratch/f11d76a9f6d6/apex-compensation-20261012 \
APEX_WORKBENCH_APP=/path/to/checkout/staff-market-workbench \
APEX_OPERATOR_WORKSPACE=/workspace/scratch/62002f3ae951/apex-source-inputs/receiving/workspace \
APEX_OPERATOR_OUTPUT=/workspace/scratch/f11d76a9f6d6/apex-compensation-20261012/operator-journey/result \
/opt/codex/runtimes/codex-primary-runtime/dependencies/node/bin/node \
  /path/to/checkout/staff-market-workbench/examples/apex-operator-journey/apex-operator-journey.mjs
```

`APEX_OPERATOR_ROOT` contains the original `native-scenarios/apex-accepted-placement-exports.zip`. The explicit output retains the same operation journal and browser origin when the executable is opened from a different source checkout.

The three executable inputs are `apex-operator-journey.mjs`, `apex_operator_native.py` and `original-case.json`; keep them together.

## Workflow

The native capture leg uses the original Workspace and classification download functions. It verifies the 27 published grades, 47 role decisions, 19 target workforce rows and six accepted scenario files against the original 119,254-byte export archive.

The browser opens every source row through the original paginated inspector and downloads the accepted immediate, phased and deferred CSV/complete-source packages. It imports the original editable workforce JSON, retains the original bytes, and records a proposed planning edition for the original Fire/Rescue Assistant Fire Chief group. The edit preserves FTE 3 and current annual full-time base 104849.06, selecting the published M14 maximum 162501.04 as a planning alternative to its retained 128436.88 market salary. The original source references and other workforce rows remain attached.

The journey reloads the edited draft, returns through the cached main views, calculates from the exact selected editions, changes the visible scenario title to invalidate the preview, recalculates and retains that exact planning scenario for source review. Desktop and mobile views include complete table access.

After its owned browser and server close, the original Workspace creates a complete backup. The original restore path reopens it and compares all six accepted exports and both new planning records.

Keep the entire result directory and its browser scratch directory for continuation.
