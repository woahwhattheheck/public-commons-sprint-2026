# Original USGS native network source

The regional source edition retains the original USGS response unchanged as `native-network.json`. Its 303 native records contain the original HUC12 and ToHUC attributes, including all 217 watersheds in the retained model domain. The loader continues to accept the original compressed `native-network.json.gz` format; it retains and fingerprints the compressed bytes before decoding them for the model.

## Source origin companion

A publisher response may contain only its published fields and features. Keep its origin metadata separately in `native-network-source.json`:

```json
{
  "schema": "upstate.native-network-source/v1",
  "source_uri": "ORIGINAL_PUBLISHER_REQUEST",
  "source_member": "native-network.json",
  "body_bytes": 71787,
  "body_sha256": "2e57f86d1725526f00f16870b1b03d9168b41ea94de6d0016b20dfe15e89bcac"
}
```

The source request, original capture identity and pinned retained-source metadata are supplied by the source producer. For a compressed original, `source_member`, `body_bytes` and `body_sha256` identify the original `.json.gz` file. The complete original response stays byte-identical. The companion belongs to `supporting_files`; the original network remains a model input in `source_files`. Adding the origin companion therefore preserves the existing model result identity and input fingerprint.

The loader checks the companion schema, exact member name, original URI, byte length and SHA-256. When the complete original domain, NRCS, classified-reach and completion-response files are retained, the distinct strict validator additionally binds the original 217-HUC membership, 240 NRCS state/HUC pairs and 1,886 classified source records. Native domain records must cover every original model-domain HUC12. Existing embedded `source_reference.originals` sidecars remain supported, including safe nested `original-wbd/` members.

## Prepare and inspect

Keep `native-network-source.json` beside its original network file. The original source context directory can also contain `domain-huc12s.json`, `nrcs-domain-fy26.csv`, `classified-reaches.csv`, the two original membership/count responses, `source-context-run.json` and `classified-full-domain-query.json`. Preparation carries these exact existing companions into the new source edition.

```sh
python source_tools/prepare_watershed_context.py prepare \
  --source-context source/water_context/20261013/full-domain-water-context.json \
  --classification-coverage source/water_context/20261013/scdes-domain217-source-coverage.json \
  --native-network source/water_context/20261013/native-network.json \
  --output-dir source/water_context/20261013-native
python source_tools/prepare_watershed_context.py inspect \
  --source-dir source/water_context/20261013-native
python source_tools/watershed_source_validation.py \
  --source-dir source/water_context/20261013-native
```

The generated `complete-sources.json` registers the context and every retained scientific companion through the existing Workspace source importer. Its own generated bytes are excluded from scientific source fingerprints. The operator retains the original network and its origin companion in the report's source download cohort; normal backup and source reopening preserve those members.

## Interpretation

The native model computes distinct upstream HUC12 membership and published watershed-area totals from the retained ToHUC graph. Upstream totals exclude the focal watershed; focal-plus-upstream totals include it once. The 303-record source can supply paths beyond the 217-HUC study boundary without expanding that study domain. Original explicit reporting/upstream roles are applied only when present in the retained source records. The acquired publisher response supplies connectivity while the separately retained role-binding source remains its own source product.

This source join preserves the current merged model, selected-water CSV columns, report renderer, saved selections and completed-run receiving route. It extends the maintained preparation API with complete original-byte validation and source retention.

## Choosing another retained native network

The public helper `load_native_network_sources(directory, network_name, *, network_path=None)` returns `{supporting_files, validation}` for the selected network alone. `network_name` is the canonical retained name, either `native-network.json` or `native-network.json.gz`; optional `network_path` identifies an original publisher filename inside that directory. The helper checks original origin metadata and nested source companions without loading a different context or classified-water edition. A network chooser can replace its prior native input and its associated supporting origin files together, preserving the complete new source cohort. Its validation values remain dictionaries under `native_network_source` and `native_originals` when those sources are supplied.
