Cliché d'enregistrement – Liste intérimaire Sommaire du tableau
Le tableau montre les résultats de Cliché d'enregistrement – Liste intérimaire. Les données sont présentées selon Nom d'attribut (titres de rangée) et , calculées selon (figurant comme en-tête de colonne).
Nom d'attribut Type de donnée Description
SDR gagnante Caractère (7) Le code qui identifie de façon unique la SDR recevant des renseignements dans la transaction. Ce code s’appuie sur la Classification géographique type (CGT). Afin d’identifier de façon unique chaque SDR au Canada, le code de province/territoire (PR) à deux chiffres et le code de la division de recensement à deux chiffres (DR) doivent précéder le code à trois chiffres de la SDR.
SDRnom gagnante Caractère (100) Nom associé à la SDR qui gagne en renseignements dans la transaction.
SDRgenre gagnante Caractère (3) Genre de SDR associée à la SDR qui gagne en renseignements dans la transaction. Le genre de subdivision de recensement accompagne le nom de la subdivision de recensement pour que la distinction soit faite entre les SDR portant le même nom dans une province ou un territoire donné.
Code du changement de la SDR gagnante Caractère (2) Code associé au genre de changement de la SDR gagnante. Une liste complète des codes de changement et de leur signification figurent dans la description du Tableau 4.
Description du code de changement de la SDR gagnante Caractère (150) Une courte description associée au code de changement de la SDR gagnante.
SDRidu perdante Caractère (7) Code qui identifie de façon unique la SDR qui perd des renseignements dans la transaction. Ce code s’appuie sur la Classification géographique type (CGT). Afin d’identifier de façon unique chaque SDR au Canada, le code de province/territoire (PR) à deux chiffres et le code de la division de recensement à deux chiffres (DR) doivent précéder le code à trois chiffres de la SDR.
SDRnom perdante Caractère (100) Nom associé à la SDR qui perd des renseignements dans la transaction.
SDRgenre perdante Caractère (3) Genre de SDR associée à la SDR qui perd des renseignements dans la transaction. Le genre de subdivision de recensement accompagne le nom de la subdivision de recensement pour que la distinction soit faite entre les SDR portant le même nom dans une province ou un territoire donné.
Code du changement de la SDR perdante Caractère (2) Code associé au genre de changement de la SDR perdante. Une liste complète des codes de changement et de leur signification figurent dans la description du Tableau 4.
Description du code de changement de la SDR perdante Caractère (150) Courte description associée au code de changement de la SDR perdante.
Population du recensement affectée Nombre (8) Dénombrement de la population, calculé à partir du Recensement de 2021, qui est affectée par la transaction, le cas échéant.
Total des logements privés affectés Nombre (8) Dénombrement des logements privés, calculé à partir du Recensement de 2021, qui sont affectés par la transaction, le cas échéant.
Logements privés occupés par des résidents habituels affectés Nombre (8) Dénombrement des logements privés occupés par des résidents habituels, calculé à partir du Recensement de 2021, qui sont affectés par la transaction, le cas échéant.
Date d’entrée en vigueur Date Date d’entrée en vigueur du changement.
No. du fichier Caractère (6) Code qui identifie le numéro de transaction d’un changement donné ou d’un ensemble de changements. Le code est attribué par Statistique Canada aux fins de consignation des changements apportés aux SDR. Les deux premiers chiffres correspondent au code de province dans laquelle les SDR touchées sont situées. Les quatre chiffres suivants sont attribués de façon séquentielle dans le système de suivi au fur et à mesure que les transactions sont inscrites.

Note de reconnaissance

Le succès du système statistique du Canada repose sur un partenariat bien établi entre Statistique Canada et la population, les entreprises, les administrations canadiennes et les autres organismes. Sans cette collaboration et cette bonne volonté, il serait impossible de produire des statistiques précises et actuelles.
