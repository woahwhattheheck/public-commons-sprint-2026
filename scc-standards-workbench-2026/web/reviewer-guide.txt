CONSULTATION / CONSULTATION
Reviewer guide / Guide de la personne répondante

ENGLISH

Open the packet
---------------
Extract the downloaded ZIP and open reviewer.html in a current browser. Keep
packet.json with the download. The page includes the document, its English and
French clauses, the selected public sources and the worked cases.

Choose English, Français or English + français at the top of the page. The
Instructions & reviewer page contains the edition title, consultation dates and
the exact return instructions supplied by the operator. You may add your name,
organization and return contact there. These fields are optional.

Read and comment
----------------
Choose Read clauses or use the Clause index. Search works across clause titles
and wording in both languages. The index can show all clauses, those still to
read or those with comments. On a phone, expand Clause index when you need it.

Use Previous clause and Next clause to move through the document. Select Mark
this clause read when you have finished examining a clause. The reading count
and marks are saved with your local draft. You can mark a clause as still to
read again. Reading marks describe your own progress.

Use Add a comment on the relevant clause. Choose Technical, Editorial or General
review and the comment's language. Enter the observation; proposed English and
French wording are optional. A Whole document comment can cover a point that
does not belong to one clause.

Save comment keeps it in the working response. My comments lets you search,
review and edit saved comments. Comments are shown in groups of 25; the complete
response is available on Review & return. The maximum is 500 comments, and the
exported response file can be no larger than 8 MiB.

Worked cases show the review questions and the source-bound examples. Expand
Original source rows to see original column names and values. A blank source
value is shown as No value supplied; the Complete original record preserves its
exact stored representation. Source references link to the retained public
citation. Use the clause buttons to return to the relevant document passage.

Keep your draft
---------------
Save draft downloads a JSON draft file containing your comments, optional
reviewer details, language choice, reading marks and any unfinished comment.
Use Open draft to continue that file in another browser or on another computer.

The page also tries to save the draft in this browser. Some browsers restrict
storage for files opened from disk, so use Save draft before leaving the page.
The status bar tells you when browser storage is unavailable.

Closing the comment editor preserves unfinished wording. Its recovery panel
offers Continue unfinished comment and Discard unfinished comment. Saved
comments are separate from an unfinished edit. Opening another draft replaces
the current working response after the page asks you to confirm any unsaved
changes.

Review and return
-----------------
Choose Review response or Review & return. This page shows every saved comment
and all proposed wording together, your supplied reviewer details and the
packet's return instructions. You can go back to edit comments or reviewer
details before exporting.

Export response downloads a JSON file named for the reviewed packet. If an
unfinished comment contains complete wording, it is saved into the response
before export. An unfinished observation with proposed wording still needs its
comment text.

Return the exported JSON file using the route recorded in the packet. The
confirmation shows the downloaded filename and export time. Save readable copy
downloads an HTML version containing the complete comments and proposed wording;
open it in a browser to read or print it. Keep that copy with your response.

The page works locally. It does not need a reviewer account or network access.
A source-reference link opens the selected public website only when you choose
it. The response is returned through the channel specified by the operator.

Correct an earlier response
--------------------------
Open the original response JSON using Open draft, edit the relevant comments,
then export it again. The response and existing comment identities stay with
that return. The operator can retain the new original file as a correction and
review what changed. Add a new comment for a new point; edit an existing comment
when correcting that point.

A response or draft opens only against its original packet. Keep a separate
draft for a later packet or edition. If a file cannot be opened, retain the file
and reopen the reviewer.html supplied with its original packet.


FRANÇAIS

Ouvrir le dossier
----------------
Extrayez le fichier ZIP téléchargé et ouvrez reviewer.html dans un navigateur
actuel. Conservez packet.json avec le dossier. La page comprend le document, les
clauses anglaises et françaises, les sources publiques sélectionnées et les cas
documentés.

Choisissez English, Français ou English + français en haut de la page. La page
Instructions et personne répondante présente le titre de l'édition, les dates de
consultation et les instructions de retour fournies par la personne responsable.
Vous pouvez y ajouter votre nom, votre organisation et vos coordonnées de retour.
Ces renseignements sont facultatifs.

Lire et commenter
-----------------
Choisissez Lire les clauses ou utilisez l'Index des clauses. La recherche porte
sur les titres et le texte des clauses dans les deux langues. L'index peut
afficher toutes les clauses, celles restant à lire ou celles ayant des
commentaires. Sur un téléphone, développez l'Index des clauses au besoin.

Utilisez Clause précédente et Clause suivante pour parcourir le document.
Choisissez Marquer cette clause comme lue lorsque son examen est terminé. Le
compte et les marques de lecture sont conservés dans votre brouillon local. Vous
pouvez marquer de nouveau une clause comme restant à lire. Ces marques décrivent
votre propre progression.

Utilisez Ajouter un commentaire sur la clause concernée. Choisissez Technique,
Rédactionnel ou Observation générale ainsi que la langue du commentaire. Rédigez
l'observation; les textes anglais et français proposés sont facultatifs. Un
commentaire sur le Document entier peut traiter un point général.

Enregistrer le commentaire le conserve dans la réponse de travail. Mes
commentaires permet de rechercher, de réviser et de modifier les commentaires
enregistrés. Ils sont présentés par groupes de 25; la réponse complète est
disponible dans Réviser et transmettre. La limite est de 500 commentaires et le
fichier exporté ne doit pas dépasser 8 Mio.

Les Cas documentés présentent les questions d'examen et les exemples liés aux
sources. Développez Lignes des sources originales pour lire les noms de colonnes
et les valeurs d'origine. Une valeur vide est présentée comme Aucune valeur
fournie; l'Enregistrement original complet conserve sa représentation exacte.
Les Références publiques mènent à la citation retenue. Les boutons de clauses
permettent de revenir au passage concerné.

Conserver le brouillon
---------------------
Enregistrer le brouillon télécharge un fichier JSON comprenant vos commentaires,
les renseignements facultatifs, la langue choisie, les marques de lecture et
tout commentaire inachevé. Utilisez Ouvrir un brouillon pour le reprendre dans un
autre navigateur ou sur un autre ordinateur.

La page essaie aussi de conserver le brouillon dans ce navigateur. Certains
navigateurs limitent le stockage des fichiers ouverts depuis le disque. Utilisez
donc Enregistrer le brouillon avant de quitter. La barre d'état indique lorsque
le stockage du navigateur est indisponible.

La fermeture de l'éditeur conserve le texte inachevé. Le panneau de récupération
permet de Reprendre le commentaire inachevé ou de l'Abandonner. Les commentaires
enregistrés sont distincts d'une modification inachevée. L'ouverture d'un autre
brouillon remplace la réponse de travail; la page demande une confirmation si des
modifications restent à enregistrer.

Réviser et transmettre
---------------------
Choisissez Réviser la réponse ou Réviser et transmettre. Cette page présente
tous les commentaires enregistrés et les textes proposés, vos renseignements et
les instructions de retour du dossier. Vous pouvez revenir modifier les
commentaires ou vos renseignements avant l'exportation.

Exporter la réponse télécharge un fichier JSON nommé d'après le dossier examiné.
Si un
commentaire inachevé contient une observation complète, il est conservé dans la
réponse avant l'exportation. Un texte proposé dont l'observation reste vide exige
que vous rédigiez le commentaire.

Transmettez le fichier JSON exporté selon le mode indiqué dans le dossier. La
confirmation présente le nom du fichier et l'heure de l'exportation. Enregistrer
une copie lisible télécharge une version HTML comprenant tous les commentaires
et les textes proposés. Ouvrez-la dans un navigateur pour la lire ou l'imprimer
et conservez-la avec votre réponse.

La page fonctionne localement, sans compte de personne répondante ni connexion
réseau. Un lien de référence ouvre le site public sélectionné uniquement lorsque
vous le choisissez. La réponse est transmise par le canal indiqué dans le
dossier.

Corriger une réponse antérieure
------------------------------
Ouvrez le JSON de la réponse originale avec Ouvrir un brouillon, modifiez les
commentaires concernés, puis exportez de nouveau. Les identités de la réponse et
des commentaires existants sont conservées. La personne responsable peut retenir
le nouveau fichier original comme correction et examiner les modifications.
Ajoutez un commentaire pour un nouveau point; modifiez un commentaire existant
pour corriger le même point.

Une réponse ou un brouillon ne s'ouvre que dans son dossier original. Conservez
un brouillon distinct pour un autre dossier ou une nouvelle édition. Si un
fichier ne s'ouvre pas, conservez-le et rouvrez le reviewer.html fourni avec son
dossier original.
