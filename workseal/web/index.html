WorkSeal / local evidence demo

Pay the accepted work generation, not an agent’s assertion.

This demo creates a local Ed25519 verifier key, normalizes a retained GitHub Actions success record, signs an ACCEPT receipt, binds that signed authority into a settlement intent, and verifies the whole bundle in-browser. It performs no network request, wallet action, RPC call, or transfer.

1. Evidence

Exact repository, workflow bytes, commit, run attempt, raw-response digest, successful jobs and steps.

2. Acceptance

Ed25519 signature covers the exact acceptance receipt; verifier fingerprint is pinned into the signed acceptance digest.

3. Settlement

The intent binds task, result, signed acceptance authority and funding reference. Chain execution remains separately authorized.
