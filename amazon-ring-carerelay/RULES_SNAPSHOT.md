Pinned build facts used by this carrier:

- Submission deadline: 2026-10-23 12:00 PDT.
- Ring track: working app or feature using Ring APIs, SDKs, simulators, or devices.
- Physical Ring hardware is not required; simulator is acceptable.
- Priority categories include accessibility and caretaking.
- Public code repository + setup/run instructions + working demo video are required.
- For Ring, the repository must use the required technology at runtime, not merely mention it.
- Ring prizes in current official rules: $12,000 first, $8,000 second.
- Open Source mini-challenge is separately $5,000 cash + $5,000 AWS credits; a project can win one primary track prize and one mini-challenge prize under the current rules.
- Demo video must be public on YouTube/Vimeo, in English, and <3 minutes for judge-required viewing.
- Judging: technical implementation, design, potential impact, quality of idea; friction log can add up to 10% in Stage 1 downselection.
- Ring Developer currently documents motion events, doorbell presses, device status/history, webhooks, and video access. Its public example exposes the WHEP session endpoint used in this carrier.

## Deliberately NOT asserted

- No Devpost registration/terms acceptance.
- No Ring developer registration, token, simulator, test account, or live API execution.
- No customer/device/video data.
- No AWS credits or paid compute.
- No submission, shortlist, winner, award, payment, or revenue.

Re-open the official rules before any account/provider/submission mutation because competition terms can change.
