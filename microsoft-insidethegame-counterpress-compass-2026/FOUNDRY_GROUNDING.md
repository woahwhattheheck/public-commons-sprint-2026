# Counterpress Compass — bounded optional AI draft guard

The match-derived deterministic caption remains the canonical fact. Microsoft Foundry is opt-in; its generated copy is NOT authoritative and is displayed only after a conservative quantitative pre-display gate.

The guard requires the existing evidence-IDs and canonical overlay, rejects mentions of unobserved `eNNN` event IDs, new quantitative values outside the original caption/metrics, unsupported goal/score/shot/penalty/xG or percentage claims, and obvious status contradictions (successful recovery vs observed expiry vs interrupted unknown). It also rejects long/HTML/link/control-character drafts. The optional AI route returns an unavailable status on rejection and retains the original deterministic caption; it never replaces evidence data.

**Limit:** this is a lexical and numerical filter, not proof that every accepted natural-language statement is correct. It cannot reliably detect arbitrary invented people, causal inferences or subtle semantic errors. Keep the `OPTIONAL FOUNDRY DRAFT · HUMAN VERIFICATION REQUIRED` label and require a human review before external broadcast use. A guard pass is not a real Foundry test, contest submission, score or financial result.

Focused check: `node --test test/draft-evidence.focused.test.mjs` (no Azure credentials, external calls or full test suite).
