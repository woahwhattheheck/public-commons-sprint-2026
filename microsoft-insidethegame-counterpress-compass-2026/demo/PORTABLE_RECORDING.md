# Receive a saved Counterpress recording

The integrated recipient journey can open the complete saved public handover even when the historical capture's private collection checkpoint is unavailable. It imports the retained coach review into a fresh recipient collection, keeps the original movie unchanged, and runs the existing edit, export, independent import, reopen and standalone HTML replay journey.

## Select the preserved edition

Use the existing `--receive-video`, `--receive-proof`, `--captured-output`, and `--resume true` options with `--receive-portable true`. The captured-output directory must contain `capture-portable.json` (schema `counterpress.portable-capture.v1`) and the four exact public files named by its `files` map: `captions.srt`, `captions.vtt`, `Counterpress_Automatic_Story.json`, and `prepared/captured-review-for-recovery.json`.

The descriptor retains the saved archive's exact SHA-256, byte length and 300-member count; the historical checkpoint digest; all 154 original frame identities and timing; eleven caption intervals; and the full 58-entry captured source map. The producing finalizer verifies the original archive and every member against its retained manifest before publishing this descriptor. It also binds the existing H.264 proof to the original lossless movie and actual MP4 bytes.

The descriptor is public source provenance. It does not contain or recreate the original private collection capability. The recipient owns a new private checkpoint containing only its actual newly created authority. Receiving output records `sourceMode: saved-portable`, `originalPrivateCheckpointAvailable: false`, the saved archive identity and the descriptor digest.

## Preserve the movie and source history

No encoder or new screen capture runs in this mode. The selected MP4 must retain the original 154-frame/155-packet, variable-timing proof. The complete handover preserves every original JPEG, timing file, lossless Matroska movie, review, story and source identity. Current application files remain a separately identified receiving edition; they are not relabeled as the historical captured source.

The existing recipient operation imports the full coach review, preserves the sender edition, commits an explicit recipient edit, exports it, imports it into an independent recipient collection and reopens it. The standalone HTML retains editable match export and caption delivery. Browser collections and private receiving checkpoints stay outside the public portable package.

A failed historical native command remains unchanged. A corrected whole continuation is linked to that terminal result using the maintained failed-command continuation helper and the original logical operation.
