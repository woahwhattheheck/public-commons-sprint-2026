## Actual operated course

The function first exports and fully verifies the original workspace with the complete application and every object. It checks the selected immutable customer review and published source. The original baseline is retained before any new request.

It then navigates the real authenticated operator desk, opens its complete downloaded working copy and reconciles any matching exact pending save. A pending operation belonging to a different review/recipient remains retained for its existing owner.

The requesting operator uses the real form to select the saved edition, enter recipient details and instructions, open the complete preview and save. A lost reply reopens the unique original request by its retained reference and validates all original selected fields. It never creates another request just because the progress message was lost.

From the actual Saved request control it downloads the full editable recipient HTML. That exact downloaded file is opened in the original browser context. The recipient fills the actual response controls and opens every original item disclosure. Full response JSON, editable HTML and working JSON are downloaded through their real controls and retained as complete files.

The recipient document is captured at 1440 and 390 pixels. The function separately opens the working JSON, returned JSON and edited HTML through their actual import/reopen flows. Re-export must preserve the identical original response ID, time and complete bytes when entered content is unchanged.

Back in the original operator desk, the actual returned file is opened, fully previewed and explicitly retained with the receiving operator and note. Desktop and narrow preview/history captures are preserved. A previously accepted exact response is reopened from native history rather than sent with another operation ID.

Full JSON and printable history are downloaded through the real controls. The actual history HTML is opened at both widths. The operator's complete working copy is retained with its remaining pending state. Each accepted native mutation is replayed using its original action, exact input and original operation ID; source records retain all fields even if the browser profile was lost. Existing browser history, when present, must match those immutable accepted records.

The complete final workspace is exported through the original client, downloaded fully and validated. Only the two original recipient operations may have been added; all preceding source, observations, decisions, reviews and operation IDs must remain identical. The matching full application is received into this course's explicit independent directory. The actual received store is imported from that directory, its complete history is opened, and its full application/object/state re-export must be byte-identical.

# GitHub: no private repos, no Actions spend (owner mandate, Bryce 2026-10-09)

## Rule
- GitHub work happens **only on PUBLIC repos**. Coordination happens in **Slack or on-machine**.
- **Never** create or push to a **private** repo.
- **Never** add, enable, or depend on **GitHub Actions / workflows** — no `.github/workflows`,
  no cron `schedule:`, no `pull_request_target`, no governance/collision/ship-enforcer CI.
- Public-repo Actions minutes are free; **private-repo Actions minutes are the only kind GitHub bills.**

## Why
On 2026-10-09 the swarm had wired its own governance/coordination CI onto private repos. The
private `woahwhattheheck/commons` repo alone had **40,000 workflow runs** and was still queuing
new jobs on every push/PR (`open-door-guard`, `muhlnickel-spec-guard`, `pr-collision-notice`,
`source-parses`), plus `smb-showcase-inventory` (10,122), `LocalDeviceAgent` (2,199) and others.
That blew past Bryce's deliberately-low billing tripwire and tried to charge the card he keeps
empty as a backstop. Bryce's standing policy is that this work belongs in Slack / on-machine /
public repos, never private GitHub with CI.

- Guard: `C:/Users/lucys/.commons/github-actions-guard/guard_actions.py`
  - Reads `github/woahwhattheheck` and `github/tokenjunkielabs` from the shared vault in-process
    (never prints the token), lists each account's owned non-archived **private** repos, and
