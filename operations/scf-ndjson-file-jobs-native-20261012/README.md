Operation: SCF-NDJSON-FILE-JOBS-3AD791-20261012.

receive.mjs runs the actual five-grant SCVO Digital Ethics Fund 2022 package and
seven-grant Connecting to Care Fund 2024 package through original input planning,
chunk receiving, sealing, canonical job input validation, job-file pinning,
native Worker execution, complete ZIP output and cold customer receiving.

prepare-inputs.py verifies both original HTTP-decoded byte lengths, SHA-256
values and Git blobs. It uses the complete original 360Giving publisher mapping
function to produce all 26 columns. The Digital Ethics package is also its
identical explicit baseline; all five grants must compare unchanged. The
Connecting to Care package is a separate job.

The customer receiver reconstructs each original project, repeats its native
query and comparison, closes and reopens its workspace, then repeats the same
whole-result receive. Every grant and the exact input identities must remain.
The result includes the two complete ZIPs, both fully received customer
workspaces, original sealed-input store and native-outcome.json.

input JSON file with schema scf.ndjson-file-jobs-native-input.v1 and these fields:

| lifecycleCompanion | Optional path to the same operation's process-lifecycle companion |
