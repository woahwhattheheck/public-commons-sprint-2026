## Application conventions and scope

The source states the rates and price formula. The following are explicit implementation choices:

- Decimal input is stored as text; exact scaled-integer arithmetic retains up to six rate decimal places and four quantity decimal places.
- Each line rounds to cents, half upward, before summation. The source does not prescribe that convention.
- Incomplete inputs produce an incomplete total and a labeled known subtotal.
- An undefined zero-denominator price ratio returns no score.
- Agency evaluation is represented only by planning inputs and the original formula; the application does not infer actual evaluation.
- Per-order translation minima require an order reference and language. Split components of one order need consolidation by the operator.
- Preparation states and reference text describe the operator's work; submission receiving remains a separately recorded actual event.
- Proposed expenses and approved, receipted expenses have separate states.
- Generic workplan identity and revision are independent of the original sales/assignment record. Keep their references together in that original workflow.

The original contract's data/security review, scientific responsibilities, assignment acceptance and ownership provisions remain with the actual prime/agency engagement. This application is a preparation and costing tool over public procurement definitions. It preserves the existing commercial workflow for contract decisions, invoices and any resulting payment claims.
