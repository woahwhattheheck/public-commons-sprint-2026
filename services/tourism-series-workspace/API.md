# Tourism Series Workspace API v1
All pure synchronous exports from services/tourism-series-workspace/engine.mjs, importing {sha256Utf8,sha256Bytes} from './sha256.mjs'. Every mutation returns {workspace,receipt,replayed}; keep workspace. Common mutation input {operationId,expectedRevision,at} where at is explicit ISO. Completed exact request replay precedes CAS; altered request with reused operationId conflicts. IDs are exact ASCII [A-Za-z0-9][A-Za-z0-9._:-]{0,127}. Opaque CSV cell identifiers are preserved verbatim.

createWorkspace({id,title,createdAt}) -> workspace {schema,id,title,createdAt,revision,files,sources,registries,mappings,mappingHistory,corrections,analyses,reports,targetPlans,targetReturns,operations}
importFile(ws,{...common,id,filename,mime_type,content_base64,source_url:'',publisher:'',published_at:'',retrieved_at,representation:'original'|'authored_transcription'|'extracted_text',note:''}) -> receipt.result.fileId. ID supplied explicitly; same id different bytes/metadata rejects. All original binary bytes retained (32MiB/file).
importCsv(ws,{...common,id,role:'source'|'target',filename,text}) -> receipt.result.sourceId. Complete text/duplicate headers/ragged rows retained; rows are {id:sourceId+':r'+(zeroBasedIndex+2),record,cells}.
saveRegistry(ws,{...common,registry}) -> receipt.result.registryId. Full immutable registry exact Scout contract plus ratio_pairs and reconciliations; id cannot overwrite another edition.
saveMapping(ws,{...common,sourceId,registryId,columns:{canonicalField:zeroBasedColumn},constants:{canonicalField:literalString}}) -> receipt.result.mappingId. Every canonical field explicitly mapped OR constant, never both; incomplete mapping accepted and yields findings. Latest mapping per source stored in ws.mappings[sourceId], history retained.
saveCorrection(ws,{...common,sourceId,rowId,column,value,actor,reason}) -> receipt.result.correctionId. Attributed raw-cell overlay, no original mutation.
project(ws,{registryId,sourceIds}) -> {registryId,basis_sha256,rows,issues,coverage,ready}. rows {rowId,sourceId,record,rawValues,values,normalized_value,currency,valid}; missing statuses have null normalized_value.
runAnalysis(ws,{registryId,sourceIds,kind:'sum'|'difference'|'percentage_change'|'ratio'|'reconcile',rowIds,dimension?,partitionId?,ratioPairId?,reconciliationId?,tolerance?}) -> {kind,selection,basis_sha256,operands,result,issues,qualified,ready}. Difference uses rowIds[1]-rowIds[0]; reconcile rowIds[0] total then declared components; tolerance exact nonnegative decimal optional default0. result includes value or exact rational {numerator,denominator,display,places:6}, unit and dimensions as applicable.
saveAnalysis(ws,{...common,id,title,actor,note,analysis:runAnalysisOptions}) -> immutable full ws.analyses entry {id,title,actor,note,at,revision,request,result}; no mutable overwritten analysis.
saveReport(ws,{...common,id,title,actor,note,analysisIds}) -> immutable ws.reports entry containing complete selected frozen analyses, exact original file/source identities and basis/history head. Full sources remain in workspace/handover.
prepareTarget(ws,{...common,id,registryId,sourceIds,rowIds,templateFileId,columns:[{column:zeroBasedTemplateColumn,field:canonicalField|'normalized_value'|'rowId'} OR {column,constant:string}],keyColumns:[zeroBasedTemplateColumn],actor,note}) -> immutable ws.targetPlans entry {id,headers,rows:[{rowId,cells}],csv,bytes,sha256,...complete mapping and source bindings}. Every template column requires explicit field/constant. Exact actual template header retained. Required keys nonblank and unique; no provider/API invocation.
recordTargetReturn(ws,{...common,id,planId,sourceId,columns:[{preparedColumn,returnedColumn}],actor,note}) -> immutable ws.targetReturns entry with complete exact original returned-source binding and {matched,missing,unexpected,duplicates,differences,extraColumns,ready}. sourceId selects actual role target CSV. All prepared columns mapped once to returned header indexes; extra native cells retained. Zero/missing/status/dimensions compared as exported; no cloud-ingest claim.
validateWorkspace(ws) -> ws; importWorkspace(fullJsonText) -> ws; exportWorkspace(ws) -> pretty full JSON plus newline.
buildHandover(ws) -> {schema,workspaceId,revision,files:[{path,type,content,bytes,sha256} OR {path,type,base64,bytes,sha256}],manifest}; all original files/CSV, corrected CSV, registries, analyses/reports readable HTML+JSON, frozen target CSV/mappings/returns, complete workspace and original history. Portable safe member paths.
renderReport(ws,reportId?) -> complete readable HTML.
metadata() -> {schema,limits,fields,statuses,analysisKinds}; FIELDS exported ordered canonical field names. parseCsv/encodeCsv/decimal also exported.
Limits32MiB each source/file;128MiB pretty UTF8 workspace;100000 rows512columns/cell1Mchars; ceilings not measured throughput.
