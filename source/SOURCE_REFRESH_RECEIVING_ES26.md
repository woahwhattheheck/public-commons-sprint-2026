Unchanged selections keep their original IDs and source bindings, including metadata-only changes. “Refresh complete” describes the replacement operation; the Native run state column shows whether each model run has completed. Earlier runs and reports remain available. When refreshed elevation, land cover, precipitation, soil, boundary or table inputs change, a difference from the previous run includes that source change. Use matching spatial support, model period and explicit scenario/profile design before interpreting a difference as a conservation benefit.
