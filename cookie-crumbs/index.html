    What this app will—and will not—do

    • Uses the Cookie Chain community RPC and the standard Solana Memo program.
    • Requests a Nightly signature only after showing the exact memo bytes.
    • Never asks for a seed phrase, private key, bridge deposit, token swap, or custody.
    • Writes only when you click the on-chain action; rejected signatures are terminal.
    • Indexes only the connected wallet’s recent public transactions.
