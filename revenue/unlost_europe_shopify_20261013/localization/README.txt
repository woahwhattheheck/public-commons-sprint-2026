Start with Merchant context. The dated research identifies the original company, public contact, languages observed and suggested product comparison.

1. In Pilot scope, enter the actual merchant's selected language, current process, reviewer and product/page. Keep unconfirmed fields blank.
2. In Content & review, add the selected source text and an entered translation. This workspace keeps the actual text; it does not translate or publish to Shopify.
3. Add preferred terms or protected names in Glossary. Literal reminders help the reviewer inspect wording; they are not a language-quality score.
4. Record the reviewer's decision. Source, translation, tone and applicable glossary changes make an earlier review visibly out of date while preserving the previous translation and decision.
5. Save a named handover, download its complete JSON/report, and keep the full working file. Open that working file in the same edition to continue all original research, edits, decisions and history.

The free edition contains one original merchant. The paid edition contains its five original merchants. Each works offline and includes complete application source. Browser storage is convenient; the downloaded working file is your portable copy. The content CSV is a human review worksheet, with spreadsheet formula prefixes escaped. Use the complete working JSON for lossless receiving.

Commercial terms in Pilot scope are your entered notes. The original five-profile research package price and the translation app's own plans are separate. Confirm any current app offer in the actual app before selecting it.
