## Reproduction and continuation

From an installed complete source tree:

~~~sh
python3 -B examples/OPERATOR_PRACTICE.py /absolute/new/private/audit-practice \
  --original-file /absolute/retained/1442341-event.pdf
~~~

The original notice argument is optional when demonstrating only the bundled references and marked records. Its absence does not fabricate an acquisition result.

The driver writes a private operation journal before each state-changing service call. It keeps the original operation IDs and requests for continuation, preserves both invalid and corrected sources, and returns the retained result when the same completed operation is opened again.

The journal excludes access tokens and the recovery passphrase; the recovery key is an independently protected local file. Private workspaces, their journals, keys, source bodies, and output artifacts are excluded from the public source release.
