# MapRank agency pilot programme

Open profiles/sample.html or profiles/paid.html for the selected original agency research. Open pilot/sample-desk.html or pilot/paid-desk.html in a modern browser, then use Open working file to select the corresponding complete blank JSON in this folder. The source JSON contains all application, style, checksum, renderer and operating-guide bodies.

The seven working views cover agency selection, actual client/location intake, dated account entitlement and measurement scopes, original result files/point observations, comparison/findings/client decision, complete handover and the source-linked guide. Each pilot starts with blank client results. The researched agencies are potential fits; creating a local case does not onboard them or contact anyone.

A scope preserves exact keyword, business identity, account snapshot and geometry. Any changed definition becomes a new scope; corrected results preserve their originals. Enter all expected coordinates or use summary-only intake. The app distinguishes ranked/not-found/error/missing. Provider averages stay under their original labels. Found-only local mean and coverage denominators are stated separately.

Save working file downloads every retained observation, source attachment, scope and history. Open the downloaded JSON in a fresh copy of the same selected app, confirm client/location and actual result counts, and continue editing. Browser local storage is convenient; a persistent warning means the current complete record must be saved before closing. A different tab changing the saved copy is rejected before an overwrite. Selected free and paid customer scopes remain separate.

The client handover contains a current completed decision, original result references and explicitly selected client attachments. The readable report omits internal intake notes. A later material edit requires a new decision review. Publication history records an actual approval/share/withdrawal; downloading a packet does not send it.

Source file limit is 5 MB per attachment. Exact bytes and SHA-256 are checked on receipt and reopen. Whole working files are local downloads; store sensitive client material using your usual controlled storage. Keep API keys/passwords in the existing credential manager and use a nonsecret custody reference in this desk.

The companion does not run scans or modify MapRank. Use the existing authorized account for actual observations and record current account entitlements, app quote and actual charges. Current app pricing controls changed public plan fields; preserve legacy account terms.

## Complete receiving

The producing worker opens, looks at and uses the exact product at desktop and phone widths, every shipped attachment, original/source documents, individual and complete archive downloads, extracted files and a fresh working-file reopen. The actual course must reach an entered client decision, then a later edit requiring review. A source read, checksum or screenshot capture alone does not replace personal use and image inspection.
