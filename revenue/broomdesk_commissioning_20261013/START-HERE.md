# BroomDesk complete commissioning package

Start with profiles/sample/lead-pack.html or profiles/paid/lead-pack.html and its complete source-qualified company selection. This package keeps the original reviewed profiles and adds an editable commissioning desk for the same one-company or five-company selection.

1. Extract the complete archive to one directory.
2. Open desk/sample/commissioning.html or desk/paid/commissioning.html in a current desktop browser. The same file adapts to a phone.
3. Read Guide, then create a pilot in Setup for an original selected company. The starter contains no invented client properties, crew, visits or earnings.
4. Receive original files in Intake. Retain actual references and complete row disposition; add the selected property, crew and dated visits.
5. Review single-visit or series changes. Carry out live actions in the authorized BroomDesk account and record the actual observed result. The desk's planned changes do not operate that account.
6. Receive actual time and payroll export sources, review the selected period, and record the owner's operating decision.
7. Save the complete working file, download the selected handover, and open the saved working file in a fresh copy. Download and read every selected original before accepting the handover.

Contents:
- profiles/: the five exact reviewed original profile members, including the original manifest.
- desk/sample/commissioning.html or desk/paid/commissioning.html: complete editable application, original company selection and operating guide.
- desk/sample/blank-working.json or desk/paid/blank-working.json: complete empty working file for this selection.
- desk/sample/application-source.json or desk/paid/application-source.json: all complete application source bodies and exact selected seed.
- START-HERE.md: this guide.

The complete application source can be downloaded from Delivery after opening the desk. To rebuild from desk/sample/application-source.json or desk/paid/application-source.json, write every files entry to its relative path, then use the included render.cjs with its exact seed and files object. The standalone application has no external runtime, account credential or installation dependency.

Browser saving is best effort and its result is displayed. If storage is unavailable, retain the working-file download before closing. A second tab's changed saved state is protected from overwrite. Original attachment bytes and ordered changes are included in the working file.

Property access fields are references to the operator's existing secure custody. Keep access codes, passwords, payment credentials and unnecessary employee personal data in their original secure systems. Share the full working file only with the intended operator. The client handover excludes secure access references and payroll employee references.

## Complete receiving

Open the actual selected desk on desktop and phone; use its ordinary controls to edit a property/crew record, review a dated change, receive an original file, correct a validation error, approve the selected actual time/export and make an owner decision. Download and independently reopen the working file and complete selected archive, including every original member. Read the whole guide and handover, inspect the visible screens for wrapping, readable controls and usable downloads. Preserve the whole original operation when continuing it on another authorized machine.

Original company research remains a fit hypothesis from cited first-party sources. The current offer and original delivery records stay with the existing customer conversation.
