# OTOBO configuration handover adaptation

TokenJunkieLabs' source-preserving review and independent-return reconciliation for the ten native OTOBO standard configuration families.

- Open `dist/otobo-review.html` or the maintained browser module entry.
- Follow [OPERATING.md](OPERATING.md) for captures, complete decisions, attributed plan editions and returned-target review.
- Follow [NATIVE_RECEIVING.md](NATIVE_RECEIVING.md) for the native YAML capture/emitter and original Migration Acceptance runtime.
- Original YAML bytes and tagged values remain in the capture; the browser contains no YAML parser.
- The native comparison uses independently captured target configuration and the original project/approval history.
- SOURCE_MANIFEST.json records complete adapter source; SOURCE_REUSE.json records reused maintained components.

Configuration captures and actual operator workspaces belong in the operator's authorized storage. The public product includes only authored example configuration and generic implementation.
