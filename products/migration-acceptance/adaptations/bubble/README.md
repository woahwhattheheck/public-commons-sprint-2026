# Bubble migration capture and review

This installed adapter joins complete read-only Bubble Data API capture to the original Migration Acceptance Workbench. It retains source and destination captures separately, maps exact business fields and relationships, exposes every selected record in an editable industrial review, and hands the complete source to the maintained native compiler, dlt loader, comparison, business acceptance and archive receiver.

## Open and use

Use the complete `bubble-review.html` built by `node adaptations/bubble/build-review.mjs /absolute/path/bubble-review.html`, or serve this directory inside the installed product and open `adaptations/bubble/`. The single HTML contains all adapter source, its browser dependencies, the operating guide and the complete authored reference project. It opens without an HTTP server.

For actual records, use the collector with the exact authorized application origin, live/branch path, API type names, constraints and independent population-count sources. See COLLECTOR.md. The browser receives capture files; it never receives an API credential.

Capture both selected sides independently, prepare the source bundle, open it with the complete mapping, and save the attributed edition. The original native receiver then retains every input, loads only its selected local DuckDB destination, evaluates all selected rows/relationships/controls and exports the independently reopenable application.

The example has four fictional data types and five mapped tables. A deliberate one-cent destination difference remains visible. It is a worked authoring example, not an observed nonprofit system, privacy-rule approval or completed customer migration.
