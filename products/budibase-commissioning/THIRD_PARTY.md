# Original Budibase examples

The commissioning implementation is separate from the original Budibase examples bundled for learning and source-format receiving.

The following files reproduce complete original examples from [Budibase/budibase at ce17c2e58d05dd8df4073826106445fa653fc7ea](https://github.com/Budibase/budibase/tree/ce17c2e58d05dd8df4073826106445fa653fc7ea):

| Retained file | Original path |
| --- | --- |
| fixtures/old-app.txt | packages/server/src/api/routes/tests/data/old-app.txt |
| fixtures/agency-client-portal.tar.gz.b64 | packages/server/src/api/routes/tests/data/agency-client-portal.tar.gz |
| fixtures/expense-approval.tar.gz.b64 | packages/server/src/api/routes/tests/data/expense-approval.tar.gz |

The .b64 files encode the complete original compressed bytes without changing them. SOURCE_PROVENANCE.json records their exact byte counts, digests and upstream links.
