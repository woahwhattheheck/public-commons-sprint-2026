The wrapper enters its own process group, writes its actual boot ID, PID namespace, visible proc PID, namespace PGID, session and start ticks, then execs the selected Chromium. A recovered PREPARING record may be closed as not-dispatched only while the original lock is held and no contradictory process receipt exists. A dispatched STARTING launch without a process receipt remains unresolved. No new browser is launched on an assumption that an unobserved child is absent.

Signal, catch and normal completion share the same shutdown operation. It awaits any in-flight launch, closes the browser context and exact owned group, and independently closes the server. Python waits for the original Node owner to settle; it does not kill Node early and strand a browser outside its own group.
