## Run the original operation

Use an already equipped Linux Python3.10+ host with storage for both complete compressed archives, the five selected extracted tables and the original customer workspace that follows. The downloader streams bytes and the profiler streams rows. Do not place a large department acquisition in another agent's shared-memory directory. Use the current unmodified Library upload helper from the executing session's installed Library skill, including its original companion modules, in an owned directory. The helper must consume the original JSON uploads contract and return the real per-file results. The ready-to-run source packet includes the unchanged helper closure and its existing392-byte invocation driver; it adds no provider credentials.

~~~sh
python3 acquire_nord.py \
~~~

The launcher compiles every Python source before this command. Retain the same root, source bytes, operation and inputs when continuing. A kernel flock excludes a second concurrent acquisition on that root. External coordination retains this same one acquisition across host changes.

## What is received

For each release, the entry retains the original publisher HTML and extracts the actual dep_59_csv link and its adjacent metadata link. It does not generate the archive URL. It also retains the complete original data.gouv publication metadata and reads the release-specific dictionary workbook.

The predecessor page's documentation button is a mutable resource now referring to the newer release. The acquisition therefore uses the explicit release-specific2025 XLSX URL that was independently observed responding as a spreadsheet. The complete workbook and its original sheet-cell values remain available for the source owner to verify its internal version. A successful XLSX response alone is not a semantic version selection.

Each HTTP file has its whole length/SHA256 and complete request/response history, including original URL, effective URL, Content-Length, ETag and Last-Modified. Completed files are saved immediately through the existing Library helper before the next input is acquired. Every original file has a retained durable file ID. Large HTTP bodies are streamed to disk; no complete archive is allocated in memory.

For an interrupted HTTP body, the entry retains the original partial file, response validator and exact prefix identity. Continuation requests the remaining range only when the retained prefix and validator are intact. A changed or unvalidated prefix remains preserved as an earlier attempt, and a complete original response starts in a fresh file. HTTP429/403 errors retain the original status and Retry-After for the existing owner to honor before continuation.

ZIP and TAR members are inspected without uncontrolled extraction. Unsafe paths, duplicate names, links and ambiguous selected table names are rejected. The entire original archive remains unchanged, including every unselected member. The five selected table names are batiment_groupe, adresse, rel_batiment_groupe_adresse, passage_millesime_batiment_groupe_id and metadonnees_bdnb_version. Each present full CSV is extracted, hashed, streamed through a strict complete parser and saved independently. Missing optional tables remain explicit; a missing building-group table stops input completion.

The original XLSX file is preserved alongside an inventory of its complete workbook members and complete worksheet cell values. Formula text and saved values are retained separately. This review index is not a replacement spreadsheet or a recalculation.

CSV observations include every actual header, record count, empty-cell count, literal-null-token count and observed geometry text representation. These observations do not silently declare a null meaning, convert identifiers to numbers or alter original cell text.

## Recovery

If a native process remains active, continue that process. If it ended, retain its source, root, state, downloads and all save logs. Rerun the original command after reconciling its ended owner. A complete download is reopened and hash checked; accepted original CSVs are compared against their actual archive member before adoption. Source parsing or storage failure leaves the completed publisher inputs saved for the next receiving host.

The existing Library helper returns actual save results and original file IDs. An uncertain save remains attached to its exact attempt directory and must be reconciled with that provider result before a replacement write. A source-complete manifest is emitted only after both releases and their required original building-group tables have been received.

A different department, release pair, source URL or dictionary requires a distinct explicit source selection. This entry preserves the original Nord request.

The original SIGTERM/SIGINT path drains only its own active upload helper, adopts any returned file receipts, then preserves the same acquisition state and partial files. An uncertain saved file remains attached to its original request/log; another invocation must reconcile that write before issuing another upload.
