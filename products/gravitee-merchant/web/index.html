Complete operating handover
Download the editable workspace
The package includes every original source, native definition, record revision and provider response in this workspace, plus the complete application source and operating guide.
Receive it on another machine
Use Node 22.16 or later on Linux. The receiving command verifies the complete package and writes to a new destination.
node products/gravitee-merchant/cli.mjs inspect --input handover.json
node products/gravitee-merchant/cli.mjs receive --input handover.json --destination /absolute/received-cohort
cd /absolute/received-cohort
npm install --prefix source/products/gravitee-merchant --ignore-scripts --omit=dev
node source/products/gravitee-merchant/cli.mjs serve --directory /absolute/received-cohort/workspace
Set the credential environment variables named in Connections on the receiving machine. The workspace opens with its original source and operating history.
