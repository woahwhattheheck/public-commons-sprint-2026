## Invocation

Prepare the complete source and runtime tuple:

```sh
SELECTED_PYTHON -B operations_risks_prepare.py --input /absolute/private/preparation-input.json
```

Run the entire original programme in the same accepting invocation:

```sh
SELECTED_PYTHON -B operations_risks_prepare.py --input /absolute/private/preparation-input.json --run
```

Replace SELECTED_PYTHON with the exact selected executable path. Preparation returns PREPARED.json, RISK_COMPLETE_SOURCE.json and RISK_EXECUTION_INPUT.json. The complete source manifest retains repository revision, every full byte/SHA/Git/mode identity and original receiving packet provenance. Both native and browser phases consume that same manifest.

`--run` launches only the original selected operations_risks_execution.py. It forwards the first stop signal to that exact owning child and waits through the child's host, browser, file, archive and save drain. It does not impose a timed kill on the nested execution owner. Source preparation's original guard is released before this child claims its own case execution guard.
