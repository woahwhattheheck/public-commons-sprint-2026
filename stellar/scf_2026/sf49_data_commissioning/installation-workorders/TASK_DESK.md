## Prepare this whole customer installation

Use a complete current Grant Operations source/runtime that actually contains buyer-task-desk.json. An older installed Grant Operations edition does not discover this new profile merely because a separate Task Desk installation carries it. Preserve the old installed source and select its updated complete runtime, or use the full current SF49 source/profile directory.

From that selected current Grant Operations runtime:

~~~sh
starforge grant-installation-workorder template \
  --profile buyer-task-desk \
  --seed /absolute/private/original-seed.json \
  --out /absolute/private/task-installation-bindings

starforge grant-installation-workorder prepare \
  --profile buyer-task-desk \
  --seed /absolute/private/original-seed.json \
  --bindings /absolute/private/task-installation-bindings/bindings.json \
  --out /absolute/private/task-installation-preparation
~~~

The Task Desk selected product includes those full files for the receiving engineer; the existing Grant Operations runtime supplies grant-installation-workorder and its original native Operations application.
