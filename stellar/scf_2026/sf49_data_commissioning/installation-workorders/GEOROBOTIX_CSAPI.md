# GeoRobotix Connected Systems Customer Installation

Use the existing **Customer Installation** desk to carry one civil or environmental observation integration from an agreed source window to an independently operated customer installation. The installed programme ID is **georobotix-csapi**.

The programme joins three maintained records. The original Workshare supplies the proposed commercial scope, native phase IDs, dependencies, effort, milestones and change terms. The Connected Systems workspace supplies actual provider responses, reviewed mappings, native editions, queries and receiving. The Customer Installation supplies the original operating case, assignments, selected deployment and payment authority, observed acceptance and complete case handover. Each retains its own native identity.

The result is a useful operator workflow: select a source and schema; acquire the complete agreed observation window; review time, units, quality and repeated IDs; build and query the native edition; compare a deliberate following edition; export the complete source and mapping; and receive, reopen and continue that edition in the customer's installation. The receiving operator also receives the full original commissioning case.
