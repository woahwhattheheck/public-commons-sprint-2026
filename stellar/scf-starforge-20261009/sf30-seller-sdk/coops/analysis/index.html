Analysis selection

Thresholds are analyst choices in the source unit. Blank thresholds produce no corresponding episodes. Preliminary first flags count outside-band samples; they are not inferred-value flags. “Exclude inferred” retains preliminary rows unless another selected filter excludes them.

Calculation and source context

The residual describes the difference between observed water level and a tidal prediction. Engineering interpretation belongs with the selected station, datum, dates, weather and project context.
