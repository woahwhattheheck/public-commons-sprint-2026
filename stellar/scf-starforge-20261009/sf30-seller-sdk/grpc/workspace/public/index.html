Call and message limits

timeoutMs covers the entire native call, including both sides of a streamed call. maxResponseBytes limits each protobuf message; maxJsonResponseBytes limits each normalized response record.

Server-stream responses

A native response stream yields ordered NDJSON records. Complete means every record arrived and native gRPC ended OK. Cancellation, a limit or a non-OK terminal retains an incomplete outcome.

Client-streaming requests
