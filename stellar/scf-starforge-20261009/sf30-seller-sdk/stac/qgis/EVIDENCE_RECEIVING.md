It retains the original operation LANDSAGE-PARCEL-EVIDENCE-OPERATOR-103D-20261013. The course never submits a payment, changes a sales relationship, or re-fetches a publisher source.

## Inputs and invocation

Run the full current application source. Its source inventory must include this receiver, the complete evidence domain/native/report/operator/CLI modules, the existing analyst worker and the complete original QGIS export closure. Ordinary Python executes the source, review, report and independent receiving phases. Native measurements require the existing installed QGIS runtime and completed source-bound maps.

## Whole original course

The first useful run performs the complete workflow:

1. Retain and byte-verify the original parcel, metadata, entire flood contract and all six exact response strings. Inspect and save every source through original evidence.command/AnalystJournal/worker operations. Preserve distinct FEMA and DNR roles and dates.
2. Create one named case with original parcel and separate FEMA/DNR area subjects. Bind exact original feature hashes/business fields and optional completed native map observations.
3. Save four source-backed findings/questions, with named reviewer, applicability, assumptions, responsible role and next action.
4. Save a deliberate software review checkpoint of the same case. Observe the existing findings' REVIEW_REQUIRED basis; retain that complete checkpoint; save reviewed successors under the original logical finding IDs.
5. Create a second source edition from identical FEMA response bytes, explicitly named a software receiving edition. Compare the complete source/subject/finding impact; save a decision for every affected finding, including a complete adopted finding and explicit retained earlier findings. No new FEMA publication or ordinance change is asserted.
6. Perform the selected actual native spatial observations when bindings/runtime exist. Freeze the full interpretation, named review, source lineage, native observations and explicitly selected map images in the complete report.
7. Verify every real report member and the interpretation. Export the complete original editable workspace through project.export; verify every member of its actual original manifest.
8. Receive that exact archive into a separate directory through project.receive. Compare its complete snapshot to the original archive. Reopen the SQLite workspace, replay every original completed evidence mutation with the same UUID/body and verify unchanged state/history. Receive the same archive again and retain the original receiving receipt.

The original request and worker outcome are retained under requests/ and results/. Logs are per original step. Both original operation requests and complete source state remain available after interruption. One course flock and the maintained nonblocking analyst-worker flock prevent two callers from owning the same run. An active other worker returns its real retained state; the course does not replace it. SIGTERM/SIGINT cooperatively stop the owned original worker, whose signal handler records interruption; the same request can resume. The default per-operation timeout is 900 seconds and can be selected explicitly up to 7,200 seconds.

An existing completed course returns its retained completion after verifying its original report and editable archive; it does not rebuild or overwrite later browser edits. A changed input body cannot silently take over the original directory.
