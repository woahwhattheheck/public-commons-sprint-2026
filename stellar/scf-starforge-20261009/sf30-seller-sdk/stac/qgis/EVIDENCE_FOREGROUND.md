## Run the complete original operation

Supply existing absolute paths; these names describe the selected host rather than promising an installed location:

```bash
/absolute/node /absolute/stac/qgis/evidence-foreground-receiving.mjs \
  --application-root /absolute/stac/qgis \
  --directory /private/landsage-original-receiving \
  --inputs /private/landsage-bootstrap-inputs.json \
  --python /absolute/python3 \
  --playwright-module /absolute/playwright/index.js \
  --chromium /absolute/chromium \
  --operation-timeout 1200 \
  --browser-timeout 1800
```

All required selections are explicit. `--operation-timeout` is the existing per-worker budget, default 1,200 seconds; `--browser-timeout` bounds the whole browser course, default 1,800 seconds. Both accept positive integer seconds up to 7,200. The outer bootstrap/backend phase budgets allow their original serial worker steps to complete. They do not launch competing stages.

Do not invoke the private `--locked` option. The public command opens the original operation lock with Python's ordinary nonblocking `flock`, retains that descriptor across the single inner Node lifetime, and forwards signals. The internal process verifies the inherited lock's device and inode.

Keep the entire command attached to the accepting worker's original job/session. The launcher prints only the operation, state, final result path and workspace identity. Private listener URLs and tokens stay in mode-0600 files under the original private directory.

## What the launcher operates

1. It freezes the exact bootstrap input bytes, selected paths, actual Node path, reviewer and timeouts under `controller/`. The original `analyst.binding.source_binding` selects the complete QGIS application and PostGIS adapter; the complete adjacent vector producer and receiving entrypoints join that selection. Exact selected bytes are copied into a private installation with their original relative directory layout, so the original import and source-binding rules remain intact. Every subsequent application command and browser-course import uses this isolated installation.
2. It calls the complete original native bootstrap in `native-bootstrap/`. That course preserves source capture and original vector/native identities; creates or resumes only its owned workspace; retains source imports, layers, map, completed features and map render; and emits `evidence-inputs.json`.
3. It calls the complete original evidence course in `evidence-course/`. All source editions, subject bindings, findings, source succession, affected review, native spatial observations, frozen report, full archive, independent receiving and replay remain with their original IDs.
4. It reads the actual analyst binding through `analyst/binding.py`, then starts `analyst.mjs` with its exact `--expected-binding`, source root, workspace, native runtime file, private connection file and selected port.
5. It starts the selected installed Chromium through Playwright's owned browser-server API. One accepting browser context runs the complete original `reviewEvidenceBrowser` export, including report downloads and actual HTML/PDF rendering.
6. Its `openReceived` callback starts the same maintained analyst on the independently received project. The original browser course opens it, checks retained findings, succession and browser-built report, and captures desktop/phone views.
7. It persists browser storage privately, closes its browser context and owned browser process, drains the original browser continuation, and stops only listener/phase children that it started. It retains both primary execution and cleanup errors if either occurs.

Before and after each phase, and before accepting either listener or browser results, the launcher verifies every selected source member. It also requires the actual analyst listener's source SHA to match the original maintained source binding. Retained source files are read-only (0400), and their completed directories are read-only (0500), beneath the private operation directory. Source selection adds no replacement parser or adapter.

The bootstrap and backend retain their own original journals, locks and worker lifecycles. The foreground launcher does not invent application receipts or replace their mutation code.

## Continue after an interruption

Run the same command with the same original directory and unchanged input, runtime and launcher selection. The frozen selection rejects a different input, runtime path, reviewer or launcher body being silently substituted into the existing operation. Once the isolated installation is complete, retries use its retained source bytes even if the upstream application directory later changes. An interrupted source copy resumes only from exact already-retained bytes or live bytes matching the original selected identities; it never adopts a newer source edition into this operation.

The actual original listener port is retained after its first successful startup and reused on continuation. This preserves the localhost browser origin. A new private token is generated only by the original listener; the browser connects through its actual returned URL. The launcher saves local storage and IndexedDB with Playwright's storage-state API to `controller/browser-storage.json` and restores that state in the next original context.

The browser course also retains each original phase request before observing its POST. It reconciles full action, payload, actor and workspace with pending/history and the original server journal. Ambiguous operations recover their original UUID; a new capture attempt uses a subordinate directory for screenshots and changing nonmutating exports. Keep these phase files, original receipt files and the database together.

Both the browser course's completed-result reuse and completed foreground reuse verify the original report, editable project archive, PDF, images and downloads by exact byte count and SHA-256 while streaming large files. It returns the saved result without rerunning native geometry or browser mutations. A changed or missing completed output is a receiving error, not permission to manufacture a new result.

If a process was killed outside cooperative shutdown, first inspect the existing original worker/process and locks. The public command itself does not search for or terminate unrelated processes. Do not remove another live process's lock or change its paths to bypass the original ownership.
