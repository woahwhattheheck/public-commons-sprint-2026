Provider semantics
  • Forward addresses and reverse coordinates use distinct inputs. Reverse coordinates are latitude,longitude; GeoJSON coordinates are longitude,latitude.
    • 

  • HTTP 200 can contain zero candidates. No result is selected automatically.
  • Provider quota exhaustion (402) is represented by the original upstream error contract. It is separate from the merchant's payment challenge.
    • 

  • Subscription responses may omit rate information. Returned licenses and native fields remain in customer deliveries.
