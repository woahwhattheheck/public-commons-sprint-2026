Connect an agreed supplier channel
  1. Agree the supplier identity, test and live URLs, authentication and acknowledgment rules with the receiving partner.
  2. Place the complete HTTPS channel configuration in the private host and provide the referenced environment credentials and TLS files.
  3. Start the supplier-order service with its transport configuration. Use the configured HTTPS intake listener for incoming orders.
  4. Open the channel here, prepare a reviewed document and follow the partner’s test and activation process.
The installed TRANSPORT.md guide contains the complete host configuration and service commands. A channel’s test or live setting is shown beside every prepared delivery.
