05 / MERCHANT & RECOVERY
Prepare a complete handoff

    

      

        
Original native merchant

        
        

        
        
Enter the actual network, asset, exact atomic-unit amount and recipient. The original merchant compiler validates these terms. The package includes native seller configuration, OpenAPI, generated customer SDK, original source, mapping and an operating guide.

        
      

      

        
Retain, move and recover

        
        

        
The source project contains the original NDJSON bytes, immutable mapping, projected CSV, native configuration, build review and a file manifest. Import reconstructs the dataset through the same original engine and verifies its snapshot.

        
Operate the prepared merchant

        
Extract the merchant ZIP into a private directory and use the installed toolkit:

        
starforge dataset-ndjson-merchant status \
  --prepared /absolute/merchant

starforge dataset-ndjson-merchant serve \
  --prepared /absolute/merchant --port 8423

        
Add the original seller's facilitator configuration for native settlement. The generated customer guide and OPERATING.md describe deployment and the exact selected source. Keep the source workspace and full merchant package private.
