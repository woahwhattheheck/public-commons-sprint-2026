Explicit grant corrections

Enter an array of changes. Each change identifies a grant, an exact JSON pointer, the original value and replacement as JSON text strings, a reason and a publisher/source reference. Exact JSON text keeps long numbers and significant zeros intact.

{"grantId":"original grant identifier","path":"/description","operation":"replace","expectedJson":"\"original description\"","replacementJson":"\"publisher-supplied description\"","reason":"Publisher correction","sourceReference":"Publisher message or file reference"}
