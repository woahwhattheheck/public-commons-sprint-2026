# Worked customer example

All records in this directory are fictional. The three complete CSV files supply a fresh worked project through the public native writer. It retains original CRM and billing editions, an explicit Mara Ellis merge, selected fields, a billing correction and three immutable deliveries. Other cross-source matching groups remain for review. The amount and postal-code values are exact text.

Run `node launch-example.mjs ./customer-review` from the parent directory to create and open the project. The initializer is `example-workspace.mjs`; an existing workspace is reopened without adding or changing operations.

The complete delivery separately preserves the original archived workspace under `archives/customer-review.mastering.gz`. Pass `--archive /path/to/archives/customer-review.mastering.gz` to receive that exact identity and history into a new directory. Fresh initialization and receiving an archived customer project are separate operations.
