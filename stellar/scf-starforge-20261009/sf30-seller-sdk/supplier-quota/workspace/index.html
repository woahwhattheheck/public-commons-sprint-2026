Continue on the receiving host

Keep the original upstream file and quota directories with the merchant. The private workspace backup carries the complete reviews, source revisions and operating history.

starforge supplier-accounts backup --state PRIVATE_STATE --out NEW_PRIVATE_BACKUP.json
starforge supplier-accounts receive --state NEW_PRIVATE_STATE --upstreams ORIGINAL_UPSTREAMS.json --backup PRIVATE_BACKUP.json

The account-history download above is a readable report. The private backup command preserves the complete original source documents without resolving their credential references.
