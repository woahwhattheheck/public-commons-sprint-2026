Run the maintained Node interpreter with the complete source edition, existing Chromium executable and existing Playwright module:

```sh

  --native-receiving /private/reconciliation/OPERATED_DIRECTORY_WORKSHEET_RECONCILIATION.json \
  --native-sha256 EXACT_RESULT_SHA256 \
  --native-archive /private/reconciliation/Directory_Worksheet_Reconciliation_Complete_Editable_Workspace.zip \
  --workspace /private/reconciliation-clients/workspace \

Its complete original worksheet, return, base edition, explicitly selected current edition, exact row bindings and native replay inputs are verified before client authoring. The archive must match the actual result's workspacePacket byte count and SHA256.

The complete programme first operates the original worksheet native course from the retained e0ec/c00 Directory basis, then the reconciliation native course, then this client course.
