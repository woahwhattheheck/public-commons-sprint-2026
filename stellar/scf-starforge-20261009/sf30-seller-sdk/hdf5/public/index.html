Choose a complete packet and its whole-file hash. The receiver checks all original members and reruns the exact native array selection before adopting the edition. An existing source head stays unchanged.
Receiving contract
  1. Compare the selected whole archive SHA-256.
  2. Verify the exact nine-member source, selection and output closure.
  3. Read the original HDF5 file with the configured native engine.
  4. Reconstruct values, coordinates, datatype and dataset projection.
  5. Adopt only matching immutable editions; reopen by the same IDs.
The packet includes the original file. External links, raw external storage and virtual datasets are inventoried; this release does not read unselected dependencies or infer missing-source values.
