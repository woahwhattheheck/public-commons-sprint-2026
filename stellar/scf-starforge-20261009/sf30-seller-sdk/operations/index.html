What these numbers mean

One request is one HTTP attempt, not one buyer. A 2xx response means the server finished writing; it does not prove on-chain settlement or client receipt.

Latency includes time until completion or disconnect. The p95 value is a histogram upper bound, not an exact percentile.

The live view and recent outcomes start fresh each session. When history is enabled, aggregate daily usage survives restarts in the seller’s private history folder. Individual request outcomes are never saved there.
