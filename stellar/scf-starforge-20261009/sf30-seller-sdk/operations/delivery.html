How to interpret

Native success events are recorded only after the original SDK reports successful settlement with a supported receipt. The journal is not an independent ledger audit.

Webhook accepted means the merchant receiver responded successfully; verify merchant fulfillment separately. Pending and exhausted records never send automatically here.

Operating boundary

This page reads the same SF98 outbox instance supplied to the merchant's original seller. There is no signer, approval, retry, webhook sender or customer tracking.

Use the original SF98 delivery CLI for an explicit, authorized drain or requeue. Local exports should remain private.
