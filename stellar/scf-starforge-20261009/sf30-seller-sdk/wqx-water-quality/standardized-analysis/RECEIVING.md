# Complete paired-scientific receiving

This is the same retained Potomac concentration operation with four serial scientific phases. It restores and verifies the original source, executes the original native decision/CLI workflow, exercises the scientific browser, and receives both source editions through the existing managed MCP operator.

Use the complete current application source, Node 24 with its original installed MCP dependencies, Python 3.11 or later, and the existing Playwright/Chromium runtime. The source phase reads the included original source carrier and makes no provider acquisition.

The original source selection is [../review-sheet/examples/potomac-concentrations.json](../review-sheet/examples/potomac-concentrations.json) relative to the water-quality root. Its source carrier, source/capture/review hashes, all 1,035 results and 1,112 limits remain unchanged.

The scientific operation ID must equal the original operation ID plus `-SCIENCE`, and its directory must be the original operation directory plus `scientific-receiving`. The driver stores the complete selected request and its hash before doing source work.

