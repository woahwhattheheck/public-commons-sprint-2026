Deliver the package

The download includes the merchant contract, OpenAPI, Node and TypeScript client, Python client, configuration template and working examples. The receiver creates a new customer directory with the maintained command:

starforge mpp customer-receive /path/to/mpp-package.json /private/merchant-customer

Customers configure their own payer, spending governor and limits. Each purchase captures the actual challenge and uses the original approval, signed request and recovery flow. The guide inside the package covers installation, first use and reopening an interrupted purchase.
