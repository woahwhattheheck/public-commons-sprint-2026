# SF69: Seller browser CORS repair for x402

Merchant install guide: import `createX402BrowserCors` from `./cors.mjs` and register it before x402 payment middleware so permitted browser OPTIONS preflights return 204 without payment. Provide an explicit `allowedOrigins` list of buyer origins and `allowedMethods` for real operations. Optionally provide `allowedRequestHeaders`, `exposedResponseHeaders`, and `credentials`. Default exposed headers include PAYMENT-REQUIRED and PAYMENT-RESPONSE; default requested headers allow Content-Type and PAYMENT-SIGNATURE. No wallet, signatures, paid requests, settlement or seller catalog mutation is performed by this middleware. The local native HTTP acceptance on Oct 11, 2026 passed ordinary HTTP 402 header exposure and OPTIONS bypass. Run a real permitted merchant/browser acceptance before customer deployment.
