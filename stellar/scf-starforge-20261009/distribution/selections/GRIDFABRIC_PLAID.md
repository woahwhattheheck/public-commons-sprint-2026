## Prepare and inspect the original runtime

Select the complete declared schema, OpenAPI and MCP feature groups explicitly:

```sh
node stellar/scf-starforge-20261009/distribution/runtime-install-cli.mjs prepare \
  --dir /retained/gridfabric-runtime \
  --archive /retained/gridfabric-release/ORIGINAL_ARCHIVE.tgz \

  --native --feature schema --feature openapi --feature mcp --operator

node stellar/scf-starforge-20261009/distribution/runtime-install-cli.mjs install \
  --dir /retained/gridfabric-runtime

node stellar/scf-starforge-20261009/distribution/runtime-install-cli.mjs inspect \
  --dir /retained/gridfabric-runtime --load --source
```

The installer resolves the original package's selected dependencies and writes its native runtime evidence. Existing dependency custody may be adopted only through its original validation. Keep installed source immutable and retain the returned package lock and READY receipt.

For the whole selected runtime, use Linux and Node 22.16 or later, plus Python 3.11 or later with Expat 2.6 or later for the included Utility XML reader. The standalone GridFabric application itself needs Node 22.13 or later with its built-in SQLite, Linux `flock` and GNU `mv`; its full native customer receiver also uses GNU `tar`. The GridFabric application has no npm dependencies.
