## Custody, interruption and recovery

The Python owner holds complete-receiving.lock while Node operates Applications and while Chromium closes its owned process group. It records each Node attempt's accepted PID, command, return code and signal history. A signal is forwarded to the actual child and the owner keeps the inherited lock until that child exits.

Node keeps immutable business inputs/results in control/<phase>/. A later invocation reuses an existing complete result, looks up/replays the same original request where needed, and never changes its original arguments to fit a newer branch. The current branch is separately reopened after a first-result replay.

Applications runs have numbered attempts. If a prior finally block dispatched a stop before recording its closure, that original stop is completed first. A new attempt begins only after the earlier owned run is reconciled. Stable business phase UUIDs survive process restarts.

Chromium starts in a private process group/session and records the actual visible PID, namespace PID/group, boot ID, PID namespace, start ticks and selected source identity before exec. Cleanup checks the retained group and its remaining members, including children after a leader exits. It refreshes that identity before each signal. Browser launch and close promises remain joined to shutdown.

The browser journal preserves complete input binding, original/received branch snapshots, source command intentions, conflict attempts, screenshots, exports and artifact hashes. Its finalOriginal snapshot freezes the exact branch used for all subsequent exports and independent receiving.

A completed course verifies its explicit artifact inventory on reuse. Recoverable source/report files are restored from the already retained complete phase result or exact snapshot and compared with their original descriptors. Browser artifacts retain their original observed bytes. An unexplained changed source, branch, result or artifact remains attached to the same original operation for concrete repair.
