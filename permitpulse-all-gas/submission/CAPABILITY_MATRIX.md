| Step | Needed capability | Required evidence | Current source-safe state |
| --- | --- | --- | --- |
| Create standalone public repo | Authenticated GitHub repo creation | public repo URL + exact imported source generation | OPEN — current connector can write existing repos but not create the intended repo |
| Put `hackathon.md` at repo root | write access to standalone repo | root file URL/blob after exact import | OPEN — becomes mechanical after repo exists |
| Register on Luma | participant browser/account | registration receipt | OPEN; do not create duplicate registrations |
| Live Convex backend | Convex account/project/deploy | deployment/project receipt tied to imported source | OPEN |
| Judge-open app URL | convex.site or chatgpt.site publication | public URL + exact source-generation verification | OPEN |
| Firecrawl real work | real Firecrawl credential/component execution | admitted scrape receipt with requested/provider source identity | OPEN |
| AgentMail real work | real AgentMail inbox/component | inbound provider event + dedupe identity | OPEN; no outbound email needed |
| OpenAI real work | authorized OpenAI API/project | response/action receipt tied to documented change | OPEN |
| Social share | authenticated X or LinkedIn identity | one provider-SENT post URL | OPEN; Muse/single-writer arbitration before posting |
| <3m demo video | screen recording + public video host | public video URL; actual duration <180s | OPEN; script is ready |
| Final vibeapps submission | authenticated participant browser | submission ID/URL + repo/live URL/video fields | OPEN; do not claim submission before provider receipt |

Every `OPEN` row is an external edge, not a source failure. Provider-SENT social/outreach actions become hard DNR until a genuine provider/human event.
