Connect inputs and results
                  
Each mapping names the target argument and the value to use. Select workflow inputs, an earlier step’s complete returned JSON, or this run’s identifiers. An empty pointer selects the complete object. Escape a slash as ~1 and a tilde as ~0.

                  
[
  {"target": "/requestId", "from": "run", "pointer": "/requestId"},
  {"target": "/caseId", "from": "inputs", "pointer": "/caseId"},
  {"target": "/expectedVersion", "from": "step", "stepId": "step1", "pointer": "/case/version"}
]

                  
Required result values pause a run until its native result matches. Use an exact value or a list of accepted values. Leave the list empty when a successful native return completes the step.

                  
[{"pointer": "/state", "oneOf": ["READY", "COMPLETE"]}]

                  
Use the paths and identifiers shown in your actual saved native result. Review each request’s own version, generation and confirmation fields before composing it.
