## Interpretation and limits

Each criterion uses the original fixed maximum-absolute scale over the selected source-qualified inventory and every enabled native case. Each cell applies its recorded normalized weights to those same scales. Minimize directions retain the original sign convention. Changing preferences changes the dimensionless objective; comparing objective loss across the explicitly selected preference choices is an analyst-defined sensitivity exercise. Repeated or numerous cases do not imply likelihood, calibration or independent evidence.

Each cell returns a feasible portfolio found by the maintained solver. These portfolios are deduplicated by exact unit-ID sets and cross-evaluated across all declared cells. This is not an enumeration of every feasible portfolio and not a minimax optimization. An unobserved compromise portfolio could have lower worst-case loss. The original selected portfolio remains explicit and unchanged.

For a portfolio supported in a cell, its lower loss bound is the cell's best known feasible score minus its score, bounded below by zero. Best known includes the original solver incumbent and every feasible cross-evaluated retained portfolio. A portfolio found elsewhere can improve a heuristic incumbent without changing the original solver receipt. If the original solver provides an upper bound, that bound minus the evaluated score supplies the upper loss bound. Exact loss is reported only when best known equals that upper bound. The source rejects a feasible score that materially exceeds the original bound; the small tolerance only absorbs floating-point roundoff.

A full-grid maximum loss is available only if the portfolio has support in every cell. The upper maximum additionally requires every cell's solver upper bound. Eligible-cell-only diagnostic loss remains separately named in JSON and cannot replace full-grid loss. Missing original support, unknown bounds, empty selected portfolios and zero scores keep their distinct meanings.

Cross-evaluation sums decision scores. It does not add spatially overlapping physical effects, recompute treatment union area, infer catchment connectivity or simulate a combined land-cover intervention. The saved plan's existing native union/reporting calculations remain the authority for physical outputs. Matched-family criteria retain their own baseline/treatment pair and the original common footprint across all declared families.
