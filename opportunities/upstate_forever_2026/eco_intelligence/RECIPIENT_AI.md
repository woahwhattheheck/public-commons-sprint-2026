# Optional investigation assistant

TokenJunkieLabs

The workbench's original scientific analysis, source review, saved studies, native simulations and readable reports work without an AI provider key. Investigations uses the same original source repository, evidence, scientist-controlled settings and saved history. Its optional Assistant reads registered evidence and prepares typed actions; execution remains a separate explicit action in the workbench.

In Investigations, create or reopen a named investigation. Data analysis inspects original source data and retained native results. Assistant answers should preserve original units, analytical fraction, geographic coverage, period and simulated-versus-observed basis, and refer to retained evidence IDs. Missing observations stay missing; annual modeled export is not intake concentration, and scenario spread is not a calibrated probability. History and export provide the ordinary readable HTML investigation report with the complete data companion.

If no provider is configured, the Assistant displays a configuration message. Data analysis and guided scientific actions remain usable. Configure the recipient's own authorized OpenAI-compatible HTTPS provider on that recipient's server using ECO_LLM_BASE_URL, ECO_LLM_MODEL and ECO_LLM_API_KEY when required. Keep secrets in the recipient server's existing secure environment; do not include keys in a browser, source package, workspace, report, log or email. The recipient package requires no Bryce PC, account session or owner secret. No purchase or upgrade is required: leave Assistant unconfigured when no authorized provider is available.

Questions, evidence, answers, typed plans and original task bindings travel with the editable workspace. Provider errors retain a human-readable status without recording credentials or raw provider response bodies. Shared credentials used internally for QA never travel in the recipient bundle.
