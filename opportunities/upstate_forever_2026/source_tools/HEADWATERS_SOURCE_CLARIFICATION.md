## Complete using the original native and report APIs

After the existing Workspace writer has finished, the same command can continue
the actual course explicitly:

    cd "$APP"
    "$PY" -B -m source_tools.prepare_headwaters_source_clarification \
      --workspace "$WS" --output-dir "$OUT" --complete

This uses the current Source Updates apply operation with native completion
enabled. It requires the installed InVEST version to match every selected
original model's producing version. The original input matcher decides reuse;
the helper checks the resulting actual per-model mode and source-run IDs. It

reuse; all native input and retained-stage checks still belong to the original
