## The two explicit editions

| Edition | Actual change | Native expectation |
| --- | --- | --- |
| Equivalent | Add an unused `programme_source_edition` CSV column, preserving every original native coefficient | Original matcher must accept NDR and SDR and the same reporting support |
| SDR coefficient | Add the same lineage column and multiply the selected original class's `usle_c` by the supplied positive factor | Original matcher must accept NDR and identify only the SDR biophysical-column difference |

The default class82/factor0.9 is an explicitly selected sensitivity assumption for the accepted simulated teaching case. It is not a measured coefficient, calibration result or recommendation for a real management intervention. The command requires that class to exist in the actual original NLCD grid and original coefficient table, and keeps the resulting USLE-C in(0,1]. Choose the applicable retained class and multiplier when using another cohort.

Each table is imported as its own `upstate.sources/v1` collection with the original source descriptor, source hash, exact Decimal coefficient change and course lineage. ## Actual results and continuation

The output directory contains:

- `course-state.json`: the stable original identity, completed phases, actual attempts and measured elapsed seconds.
- `equivalent/` and `sdr-coefficient/`: complete original CSVs, source manifests, refresh results, source-successor records and Programme previews.
- `programme-source-reuse-result.json`: actual Programme/report/native IDs, per-model native versus reused execution, original donor provenance, original stage and execution timestamps, output quantities and signed cross-edition comparison records.
- `programme-source-reuse.zip`: original complete Workspace plus the exact outgoing application, including all donor cases and source editions.
- `received/`: the independent editable restored application and Workspace.
- `cold-reopen.stdout` and `cold-reopen.stderr`: the actual fresh interpreter result.

The equivalent comparison must retain identical actual converted raster values/masks, matched finite valid-cell counts and zero signed change; TIFF container encoding may differ. Every report retains nitrogen/phosphorus kilograms per year and sediment metric tonnes per year separately. These are contributions to the modeled stream network, not intake concentrations. The original reporting support remains explicit; no additional cell-area multiplication is applied to the already converted annual mass summaries.

A completed phase is reopened rather than reexecuted. An interrupted native phase resumes its existing saved Programme/run IDs. An existing valid archive and completed receiving directory are reconciled through the original archive inspector and `portable.resume_restore`. The cold process executes this exact script from `received/application`, reopens all successor reports and native stages, verifies original donor identities and comparisons, and calls the existing source-successor semantic verifier. The final record includes actual timings; no speed or model outcome is promised before the receiving result exists.

This complete Workspace archive deliberately preserves every original stage donor. It is complementary to the separately maintained selected-study transfer repair for donor-relative `reused_from.original_arguments` and `previous_reuse`; the course does not replace that owner's exporter.
