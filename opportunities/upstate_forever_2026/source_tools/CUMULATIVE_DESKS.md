## Continue in the same scientific Workspace

Open the newly installed operator with the existing Workspace and original
startup configuration. The registered views now support one continuous workflow:

1. **Annual references:** inventory the retained original load_est.zip and
   sitegage.zip, inspect original station/constituent/year rows, select the actual
   upstream catchment and import the chosen annual references.
2. **Calibration and validation:** select completed native runs and original
   observations, freeze calibration/validation groups and the declared objective,
   inspect source-error sensitivity, then prepare residual maps from the completed
   calibration.
3. **Editable GIS projects:** include the retained residual-map vector source,
   export an editable project, receive a returned edition and adopt its original
   source collection through the same Workspace.
4. **Water and Habitat Context:** inspect original native fields and records,
   select the source features and HUC/utility relationships, run context analysis,
   and reopen the saved maps, complete rows and source-derived exports.
5. **Parcel Source Desk:** receive the original whole county parcel preparation,
   select a saved source context or the actual NDR/SDR baseline and alternative,
   retain study drafts and operation IDs, and use the existing Conservation
   preparation, selection and export journey.

The original source ZIPs and native model outputs remain attached to their
existing receiving operation. This cohort carries the complete code, dictionary,
provider definitions and declared original catchment geometry companions. The
native receiver reports its actual installer result, catalogue entries and first
