# Original-grid land-cover zonal operation

The kernel accepts the actual retained watershed polygons and streams the original categorical rows. It supports EPSG:4269 NAD83 through the ellipsoidal EPSG:5070 conversion, or original EPSG:5070 coordinates directly. The caller supplies the actual source CRS and original HUC12 attribute field. It refuses missing, open or curved rings and any watershed extending beyond the raster rectangle.

For each polygon, it computes scanline intersections on the native grid and counts pixels whose centers fall in the polygon under an even-odd ring rule. Horizontal and vertical boundary ties follow a half-open convention. Interior rings are retained. Source NoData remains separate. Full-raster, domain-union and individual watershed class counts are returned together with overlap counts. Area uses the determinant of the retained affine transform, preserving its original decimal values.

Use prepareZones(features, actualSourceEpsg, grid, originalIdField), then await summarizeRows(prepared, readOriginalRow, metadata). readOriginalRow(rowIndex) returns the exact native uint8 row of grid.width cells; the existing retained GeoTIFF row-strip decoder supplies this callback. metadata must retain the exact polygon-body SHA256, raster SHA256, year, source URLs and NoData code. Save the resulting ordinary JSON and convert its watershed/class rows to CSV for the existing native source importer.
