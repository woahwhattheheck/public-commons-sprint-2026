# Eighteenmile stream nutrient observations

This source cohort retains 589 original WQP result rows from four state stream stations, 2020–2025. Import the installed builtin scdes-eighteenmile-streams-2020-2025 through Published studies, select station/characteristic/year/month, and export the selected report or complete source study.

The original CSVs are unchanged. Published seasonal tables are empty because the agency query contains individual results, not a published seasonal-summary table. The source index defines nonoverlapping date intervals and exact hashes. A point-in-polygon result applies to the retained unsplit whole basin only. See source_notes.json and basin-membership.json.
