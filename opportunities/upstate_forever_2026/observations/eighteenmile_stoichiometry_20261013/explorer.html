__FINDINGS__

Phosphorus:reconstructed nitrogen (P:N) stays defined for every activity. For nitrogen:phosphorus (N:P), a below-limit phosphorus result gives no finite upper bound over positive P, and the ratio is undefined at P = 0. The explorer preserves both facts.

All concentrations are unfiltered. Reconstructed nitrogen is the original activity's Kjeldahl-N plus nitrate/nitrite-N. Sample-composition ratios are not nutrient-limitation diagnoses, annual loads or transport estimates.

Files and reproduction

This single HTML file works without a server, libraries or a network connection. The complete application-layout package additionally contains unchanged original CSVs, exact interval CSV/JSON exports, source code, the scientific report recipe and the native source manifest.

python observations/eighteenmile_stoichiometry_20261013/build.py \
  --application-root /path/to/current/application \
  --output /path/to/new-composition-package

python /path/to/current/application/source/observed-report-20261013/render.py \
  --app-root /path/to/current/application --workspace /path/to/current/workspace \
  --manifest /path/to/new-composition-package/eighteenmile_stoichiometry.sources.json \
  --output /path/to/new-native-report
Edition: __EDITION__ · Source record identity: original file SHA-256 plus one-based data row. Source values and clocks are retained verbatim. Authored software is MIT-licensed; publisher data retains its original attribution.
