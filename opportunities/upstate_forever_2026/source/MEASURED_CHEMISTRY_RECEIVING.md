## Exact source and timing

The receiver reads each original run artifact through native file verification.
The source collection retains the unchanged artifact bytes and full original
case/run documents. Its CSV adds an explicit transport representation, preserving
the complete original observation JSON in every row.

The Measurements CSV format requires a calendar field. This authored example

encoding. It makes no field sampling-date claim. The binding leaves calendar

## What the course produces

The maintained collection preview/receive API receives the complete source set.
The existing source review operation records the explicit inclusion decision for
each original reference row. Its one-transaction snapshot supplies the complete
original rows, provenance/history, portable measured workspace and revision to
the native binding producer.

The binding's complete collection editions and their original ZIPs are retained
as scientific Workspace source companions. The native Chemistry child case
therefore carries the original full source set through editable export.

The course then:

1. Checks all 36 bound values, component operators, nitrogen bases, error scales,
   model days and roles against the archived original request.
2. Runs the original native calibration with the same parameter definitions and
   checks convergence, fitted coefficients and all original predictions against
   the retained completed calibration. Parameter tolerances are relative
   `2e-5` / absolute `2e-7`; prediction tolerances are relative
   `3e-5` / absolute `3e-7`.
3. Creates the original Chemistry report source and uses the existing scientific
   composer to render the actual PDF, HTML, figures and data. All edition members
   are copied to the outgoing downloads directory.
4. Exports the source-bound case and completed run through the original editable
   Chemistry ZIP operation.
5. Opens that ZIP in a new independent Workspace, preserving the physical Project,
   original completed request and all native run artifacts.
6. Receives the full original portable Measurements workspace and every selected
   source collection ZIP into that independent copy. All original tables and
   source/review history are compared, and each edition member is verified before
   extraction.
7. Adopts the original binding source for the received case and reopens the saved
   local binding. The complete scientific request remains equal; only the
   expected receiving case/binding/source metadata is rebound. The original
   selection remains in received-from provenance. The completed received run
   retains its full original request unchanged.

The script records actual native calibration invocation time and total invocation
time. Reopening an already completed run is measured as reopening, rather than
presented as a fresh solve.
