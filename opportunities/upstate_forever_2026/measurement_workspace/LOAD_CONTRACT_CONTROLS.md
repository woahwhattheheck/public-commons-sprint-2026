## Ordinary scientific authoring

1. Open a saved original Flow study. Open Concentration and discharge loads and select that study. Existing historical and current WQP studies retain their original source rows.
2. Load an original contract, or choose Start a context-only draft from this study. A derived draft copies only original calendar, sampled stations, gauge relationships and source references. Its maximum interpolation gap is blank; the scientist must enter a positive integer. New spatial decisions are false, and censoring admission is initially empty.
3. Set first included and first excluded dates. The Flow-study end is inclusive, whereas the load-contract end is exclusive. Review the daily grab/daily-flow approximation, interpolation limit and event-targeted sampling decision. This does not fit an event correction.
4. Review literal original statuses, qualifiers, validity labels and supported left-censor conditions. Each empty list accepts no values; a listed empty string accepts a blank source label. No measured source value is rewritten. Provisional discharge is not automatically admitted by a new draft.
5. Inspect original support. A station’s gauge, relationship and flow role are read-only in this editor. Positive admission controls require the selected original study to establish co-located, matched catchment discharge for every joined station row. A regional/downstream relation remains context. Missing or contradictory original support must be resolved in a new parent study; no contract control upgrades it.
6. Add labeled seasonal date intervals if needed. Each lies inside the selected calculation window, with exclusive end. An optional native comparison selects the exact original method/fraction series from a preview and supplies original species and evidence. The maintained engine still requires eligible species/fraction/basis, full calendar coverage, uncensored mass and explicit matched catchment support.
7. Preview, inspect original measurements, excluded rows, coverage and retained censor bounds, then save that exact preview. Any contract or parent edit invalidates the previous preview. Saved results reopen their original contracts and preserve prior scientific identities.
8. Download the edited contract and the separately retained loaded original. Advanced JSON remains available for exact existing source shapes and unknown fields. Labeled controls change only the selected field; untouched unknown fields, list order and blank values survive.

A context-only result is a useful retained scientific product. It is not a missing zero load. Native output remains delivery to streams; these observed-load estimates do not become intake concentrations or realized intervention benefits.
