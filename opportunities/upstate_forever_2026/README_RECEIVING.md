# Upper Savannah economic decision companion and operator integration

TokenJunkieLabs · Ecosystem Sciences sprint · October 12–13, 2026

This package contains the complete economic decision companion and its Economic desk integration for the existing scientific application. It reads completed baseline/scenario comparisons or an original ASTRA-S1 watershed report, preserves the study and selected pollutant identities, applies sourced implementation costs and budgets, and exports a portable decision edition.

## Receive the component

The source ZIP contains the model companion, its source receiver and operating guides, the Economic desk integration and authenticated receiving command, and the original Gura native comparison workflow. README_RECEIVING.md is this component guide. The source JSON and source-download HTML contain the same complete files.

    python -B receive_decision_source.py upper-savannah-decision-source.json /absolute/incoming-component

The source receiver also accepts the downloaded source HTML, including its gzip carrier. It verifies every member and preserves matching existing files. Receive a new source edition into a separate incoming directory when a retained member differs.

The Slack source bank is a gzip/base64 encoding of commons.source-bank/v1. The existing ECD1 source_tools/application_assembly.py accepts its saved complete Markdown directly as an --overlay. Select the maintained current application and its other source layers first, then this component. The combined component is additive source for that application.

## Operate the standalone companion

model/DECISION_INTEGRATION.md describes both the original-workspace route and the completed watershed-report route. Inspect the retained input first, use its actual comparison or reporting-zone identity, enter implementation costs from actual sources, and build a new decision edition.

Open the resulting index.html to compare alternatives, apply view filters, inspect source support and costs, read paired sensitivity, export tables, save a working desk and print. model/DECISION_WALKTHROUGH.md follows the controls. model/DECISION_METHODS.md explains quantities and decisions. model/COST_SOURCE_INTAKE.md distinguishes implementation-price sources from EQIP assistance amounts.

model/decision_receive.py builds from an actual completed input or accepts an existing edition, exercises installed Playwright/Chromium, and retains screenshots, downloads, saved-desk reopen, timings and print PDF. Its integration guide gives both invocation paths.

Each candidate is one complete modeled scenario. Physical outputs keep their own annual mass units. Implementation costs describe the actual intervention footprint; the modeling-service workshare price is a separate commercial quantity.
