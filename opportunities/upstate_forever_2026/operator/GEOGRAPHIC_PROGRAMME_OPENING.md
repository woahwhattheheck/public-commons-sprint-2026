`geography.open-programme` to the original operator queue. Its payload binds the
geographic case and original completed adoption operation. The provider rereads
that retained adoption and calls the maintained
`model.geographic_programme.save_operator_opening` through the live Operator.

selection and session-file descriptor. It uses the same
`geography-operations/<task-id>` folder as its original operation. Failed or
interrupted requests resume through the existing task controls with their
original observed revision and operation ID.

When complete, **Open saved project view** refreshes the current session and
checks the original receipt's revision and selected records. It then invokes
the Guided journey's existing Open saved project view action. That action
retains the prior browser view and notes. The selected baseline, grid, profile,
scenario, original comparison and mapped delivery appear together.

A different view saved after the request was made is preserved. The operation
reports `preserved_current`, keeps the user's actual view, and leaves the
saved Programme available. Opening does not automatically navigate after a
background task completes. An operator deliberately opens the retained view.
A later changed session cannot be opened through an older applied receipt.
