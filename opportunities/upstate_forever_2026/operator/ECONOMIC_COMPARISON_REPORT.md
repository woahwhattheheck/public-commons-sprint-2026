## Recovery and reopening

The source registration has an independent full original request in persistent browser storage. Its identity includes the Workspace, comparison ID, source identity and reviewed producer operation. The complete request is saved before submission. **Recover original request** resubmits the same operation when the response was uncertain; **Open original task** shows the accepted task. An interrupted task can be resumed. A definitively failed or cancelled request can be retained and downloaded before another preview is permitted. A pending or uncertain operation is never silently replaced.

Use **Download exact recovery file** before moving browser sessions or if storage reports an error. **Open original recovery file** validates the original Workspace, comparison and immutable payload before adopting it. File adoption is serialized across reading and persistence so a later click cannot be overwritten by an older file read. A storage failure blocks a new submission rather than losing its original identity.

The saved-source list reopens an exact source registration and refreshes its download tickets. The original source collection and complete receipt remain inspectable. Opening a report refreshes the registered source first and checks its original comparison, source and operation bindings. A Workspace change cancels the consumer operation.
