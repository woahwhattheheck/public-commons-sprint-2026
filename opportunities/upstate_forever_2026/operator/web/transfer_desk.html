What these numbers mean

Retained bytes are all original file contents. Unique bytes count identical blocks once. Missing bytes are what this receiver still needs. A complete transfer does not run or alter the scientific model.

Each part also contains the complete manifest and ZIP metadata. Its total file size is slightly larger than the block payload. Parts may arrive in any order.
