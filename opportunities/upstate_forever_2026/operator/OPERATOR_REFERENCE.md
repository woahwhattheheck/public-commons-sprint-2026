## Choose the right starting point

Open the intended workspace and read its project title before selecting sources or changing a case. Guided journey → Open data or a saved study connects the original source, grid, profile, scenario and run forms.

For your own data, choose Open original files, inspect the original names, fields, dates, units, coordinate system and missing-value codes, then retain that source edition. For a previous analysis, choose its saved source or baseline. A retained file is a preserved input; its presence alone does not establish that its values are field measurements.

Keep observed measurements, modeled native results and authored teaching inputs explicitly identified. A source vintage is a published edition label; it must not be silently turned into an observation date. The original source inspection and references remain the authority for each field.

## Change inputs and run the original calculation



1. Inspect the retained source and choose its grid, parameter profile and baseline scenario. Read the native preview and original source choices before preparing the run.
2. For a scientific alternative, save a separate scenario or profile revision with the actual change and reason. Select that saved revision in the original run form. Changing a source, grid or profile can change the scientific support and comparison meaning.
3. Prepare the run, then choose Run native models for that exact saved run. Read the task state and native stage rather than repeatedly submitting the form. A completed native case and the completion of its enclosing programme are separate states.
4. If a response is interrupted, open the original task or Recover original request. Resume original task continues that task and its retained stages. Open the retained log and selected sources when correcting a failure; preserve completed results.
5. Open the completed maps and results. Read the actual quantity, units, valid-cell coverage and source/profile selection. Reused stages retain their original origin and timestamps; current task duration is not their historical compute duration.

## Read quantities and difference signs



**Nutrient export** — NDR annual nitrogen and phosphorus export is modeled delivery to streams, ordinarily kg/year as recorded with the output. Read the actual artifact units; these are not intake concentrations.

**Sediment export** — SDR annual sediment delivery uses the retained output units, ordinarily metric tonnes/year. Do not compare a mass total directly with a concentration sample.

**Signed native difference** — Alternative minus baseline. A negative export difference is lower modeled export on the compared valid cells; a positive difference is higher. Read changed support separately.

**Reporting support** — A reporting polygon summarizes the selected physical quantity. The wider model domain supplies upstream context. Overlapping areas cannot be summed as independent unique land without accounting for overlap.

**Area and coverage** — Land-cover trajectory areas are hectares on the common fractional polygon support. Percentages use their stated denominator. Missing coverage is not a measured or calculated zero.

**Observed versus modeled** — Observation units, time basis, method, qualifiers and reporting limits must be explicitly compatible with the model quantity and geography. Keep excluded and censored rows visible.

**Terrain settings** — Burn depth is in metres and the selected half-width is not the total width. Geometric filling volume is not water storage. Scenario values describe the analyst’s terrain choice.

**Timeline persistence** — A final class present in multiple trailing selected observations is observed persistence over those selections. Gaps are explicit; it does not assert an unobserved continuous interval or future permanence.

**Forest crossings** — Forest entry and exit count any observed crossing and can overlap when land returns. Ending forest membership is a separate quantity. The selected class definitions remain explicit.

## Switch maps and read the result

Open Spatial review or the original report map. Choose the actual source, output or comparison layer and statistic, then read the legend, units, geographic extent and selected reporting area together. Retain missing-data hatching and explicit zero values.

In Land-cover changes, ordinary comparison maps and whole-history timeline maps describe different questions. Choose the desired metric and read its exact value table: stable or changed area, return to the initial class, final-class retention, or forest entry/exit. Repeated transitions are retained in the separate timeline summary and trajectory tables.

Inspect the original raster or geographic download when it is needed for another GIS workflow. A screen color or screenshot does not replace the original GeoTIFF, vector/table, source references and saved selection.

## Save, export and reopen



1. Save the current scientific record and operating selections in their original controls. A notes file or view-selection file records that view; it is not the complete scientific project.
2. Open each report and every relevant map, CSV, source table and working document before transferring them. Use the actual download controls so the file belongs to the selected saved edition.
3. Use Project continuity for the full project and its operating history, or the specific complete working package when continuing that product. Keep the original archive members together and follow its included opening instructions.
4. Receive the archive into a separate chosen destination, open that received workspace and check the original project, sources, saved selections and completed outputs. Continue an unfinished operation from its retained task rather than creating a replacement case.
5. For a land-cover portable archive, retain its complete report, source-year choices, six CSV tables and original-grid rasters. Use the documented land-cover receiving command to cold-open the original edition; an extracted report alone is the readable result, not the full application.

## Worked examples and their actual scope

The native terrain example is explicitly SIMULATED headwaters. Its completed 2 m conditioning alternative changes 267 cells / 24.03 ha. On 14,155 common valid cells / 1,273.95 ha, annual modeled N decreases 66.7786 kg, P decreases 5.4895 kg, and sediment increases 52.2197 metric tonnes. Nine lost valid cells remain separate. This is a completed case retained in its own original project, not an observation or a result automatically present in another workspace.

The completed original-file monitoring example retains all 208 public-source rows, including 49 below-limit results, across nine separate series and 302 same-month pairs. Its multi-year view opens the original record, qualifier and unit selections. These counts describe that retained source edition and do not supply another study’s observations.

The temporal land-cover teaching course uses a declared four-observation raster with stable, once-changed, repeatedly changed, returning, missing and unknown-code cells. Its small authored grid explains interpretation and receiving. Use the actual completed receiving output before quoting a numerical result; the live timeline controls also accept retained regional source observations.

## When a result cannot be opened

Keep the selected workspace, original operation and source choices. Read the exact current error and the original log or task details. Missing source, incompatible units/grid, incomplete native output and a lost response require different corrections.

If the application says a source or saved item changed, reopen the intended original edition or compose the actual newer source with its owner. Do not replace the original files to make an old identifier appear valid.

Use Download operation record for the full native operation when it is available. Share the actual exception, selected case and original task with the operator maintaining that project. The reference does not start jobs, change scientific settings or alter saved data.
