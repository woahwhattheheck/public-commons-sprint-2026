## Operator behavior

The existing header has **Save view and notes**. It saves the selected analysis
and operating notes into the actual workspace's operator-session.json. The
native service checks the original project identity and each selected source
collection, grid, profile, scenario, model run, baseline, comparison, map review, map pack and
delivery relationship. Saves use the current revision; conflicting browser
edits remain separate until the operator refreshes. Distinct earlier notes
remain in the saved history.

The control loads the existing registered guided controller on demand and
captures that controller's current selection. It works before the first visit
to the guided page. Changing workspaces during a pending capture cannot attach
the selected view to the other project.

The original Back up workspace form captures the same selection and notes
when opened. Its original queued request retains that snapshot. The backup
stores it before calling the existing native scientific archive. A completed
backup task continues to reuse its exact existing output. Receiving the archive
restores the original project and selected records; the complete guided
controller reopens the saved view under the new receiving workspace key.
