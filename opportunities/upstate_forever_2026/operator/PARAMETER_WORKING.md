# Parameter working designs

Named working revisions preserve incomplete or invalid form values before scientific preparation.
Open **Parameter studies → Working designs and recovery**, or use the **Working design** section in the existing Parameter form.

## Save and return to unfinished work

Enter a name and author, then choose **Save working revision**. An axis may have an unfinished value or reference; a reporting-area filter may still be incomplete. The exact text and ordered rows are retained. No profile or run is created.

The saved revision binds the chosen original native baseline, reporting-area source editions and any original calibration result. A blank baseline is valid working material; choose an actual retained baseline before scientific preview.

Every save creates an immutable revision with its author, note, timestamp and original request. Saving against an older head fails visibly. Open the current revision to reconcile, or choose **Save as new branch**. Forking preserves the complete earlier history; it does not overwrite another scientist's save.

The form also retains unfinished controls in this browser as you edit. **Download unfinished form and history** creates a recovery file that includes the exact raw values, current saved ancestry and a pending original request when present. Browser storage can be unavailable or full; a visible warning asks you to download before closing. Native saved revisions and downloaded recovery files remain separate durable copies.

## Recover an interrupted save

A save request is stored locally before it is submitted to the ordinary operator queue. **Recover original save** sends the same operation and payload, then verifies the accepted task's workspace, action, payload and returned revision. It never creates a different request to conceal an ambiguous response.

If the native task failed, its original record remains in **Operations**. Recover or inspect that original task there. An explicit new branch retains the earlier pending recovery and creates a separate request; it does not claim that the earlier save succeeded. Edits made while a save is running remain in the form.

## Inspect, export and reopen

**Review history** shows every original ancestor, author and note. You can open any revision and download its complete editable history. Raw fields and original source bindings are available in details.

A complete history file opens as a new branch. Native save verifies its immutable record hashes, ordered ancestry, original baseline and all source bindings before admitting it. It preserves all original revision IDs. Import does not replace a current series or rewrite source identifiers. If the needed native input is absent, receive the original Study or Workspace first.

A recovery file can also carry a pending request. Such a request can only be recovered in its original Workspace, with the original working-save action. A file never executes arbitrary queued actions.

## Prepare an actual scientific study

Preview and prepare remain the existing Parameter workflow. Numbers, flow algorithms, model scope, geographic filters and source availability are checked there. A working save is not scientific acceptance.

When editing a named working revision, save its changed raw fields before previewing. The validated prepared selection then retains its exact working revision as `working_origin`. The native engine independently compares that revision's normalized selection before preparation. An ordinary new Parameter form without a working history continues to use the existing preview and prepare actions.

A completed Parameter report source retains the working history as an original companion and displays its name, author and revision. Earlier unfinished values stay identified as working material. Full native inputs and all earlier working baselines are retained by the editable Study and Workspace paths.

## Portable and selected Study receiving

The ordinary Workspace backup includes and verifies all saved working histories. In **Studies**, choose **Parameter working designs** to export an unfinished history without first preparing a run or report. Capture retains its complete raw ancestry and the original baseline runs, source collections and calibration dependencies. Prepared Parameter Study selection also carries its referenced working history.

Cold receiving verifies the exact captured histories. The existing received Study view offers **Open working design and history**, which opens the actual native revision in the current Parameter desk. It preserves unfinished values, original source IDs, completed runs and immutable calibration history.

## Meaningful native receiving course

Use an existing populated Workspace and the original application/browser owner. Record the actual source revision and retain original outputs.

1. Open a new Parameter form. Enter a named draft with an unfinished numeric value, multiline scientific reference and incomplete area filter. Save, close and reopen it; verify every raw value and row.
2. Download the unfinished recovery and complete history. Reopen the complete history as a new branch. Confirm its original ancestor IDs remain intact and its native baseline/source binding matches the original.
3. Open the same native head in two ordinary tabs. Save one, then attempt the older parent in the other. Observe the conflict; fork explicitly and verify neither history was overwritten.
4. Interrupt only the browser response after an accepted working save. Recover the exact original operation. Verify one immutable revision and unchanged request/payload; do not rerun a scientific model for this check.
5. Correct the draft, save the new revision and operate the existing preview/prepare. Verify the prepared study's `working_origin`, actual baseline and calibration reference. Existing run controls own any authorized new execution.
6. Export this working design and prepared study using ordinary selected Study. Cold reopen the archive, open both native records, and inspect raw history and original source downloads.
7. View the populated interface and actual downloads at desktop and 390px width. Inspect the final report HTML and raw history files. Retain screenshots, archive and exact native receipts with the original receiving operation.

Source review and helper replay are not a claim that this physical course completed.
