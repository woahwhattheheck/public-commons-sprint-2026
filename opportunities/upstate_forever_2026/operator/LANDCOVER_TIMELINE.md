## Build and interpret the whole saved history

**Build multi-year change history** submits the original landcover.ledger.build action with input_mode timeline and ordered annual_sources. It uses the same task identity, native queue, resume and saved-edition flow. Edits made while a task runs stay in the current draft. A completed edition opens automatically only when that draft and saved-edition selection have not moved on.

Open an original completed edition to see its verified report and bindings. The multi-year view includes:

- Actual selected observation sequence, common analysis area, covered area and coverage for each original reporting area.
- Stable/changed class areas, one/multiple observed transitions, returned-to-initial and changed-without-return accounts, and the final-class observation account.
- Forest-type exchanges that stay inside the model's forest classes, separate from membership crossings.
- Complete original class-area tables for every selected year.
- Retained cell trajectories with hectares, intersecting-cell count, changes/returns, last observed-change interval and trailing final-class observations. The paginated table shows fifty trajectories at a time; downloads preserve the whole account.
- Actual adjacent-year transitions and the interpretation retained by the source owner.

Area/status filters change the view, not the calculation. Individual overlapping reporting areas must not be summed; use the retained unique domain union where supplied.

An observed reversal is a return to any previously observed class after leaving it. A → B → C → B has a return without returning to A. Returned-to-initial is separately identified.

Forest entry and exit each count a trajectory's area once if that crossing occurs anywhere in the selected observations. Forest → nonforest → forest contributes to entry, exit and return. These quantities overlap and are not additive categories. Forest-class exchanges mean changed class while every selected observation remains in the model's forest group. Developed open space is a class, not measured impervious fraction.

Final-class retention covers changed cells with at least two trailing selected observations in the final class. Unconfirmed final class covers changed cells where it appears only in the last selected observation. Neither establishes continuous duration between observations. The interval 2001–2016 locates a change between those observations, not a date within them.
