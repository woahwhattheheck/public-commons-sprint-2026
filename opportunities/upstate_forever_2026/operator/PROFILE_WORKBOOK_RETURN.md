TokenJunkieLabs. This work returns explicitly selected saved scientific values to a new named XLSX/XLSM while retaining the complete original workbook and native profile. It does not run InVEST, apply a scientific review, infer new coefficient meanings, or calculate spreadsheet formulas.

## Scientific and workbook limits

Only existing physical cells in an unsigned XLSX/XLSM are eligible. An effectively locked cell on a protected sheet, a formula (including its retained array/range cells), merged cell or unsupported cell metadata/extension is blocked. Workbook structure protection remains unchanged and does not block an otherwise editable cell; explicit unlocked-cell styles on protected templates remain usable. The reader checks native cell, row and column style selection and the retained base/cell protection formats. The operator may map an alternative cell or explicitly exclude the field with a reason. Coefficient and model values come from the selected saved profile, never arbitrary replacement text. Native numeric fields are written as numeric cells; descriptive numeric-looking text retains leading zeros as literal text, booleans remain Boolean cells, and a null native parameter clears an explicitly mapped cell. Change detection compares both the original cell type and value. Original source text and typed value remain in the full preview. Land-cover codes and original physical row positions remain visible. Units in the preview are the native source's declarations; use a destination with the same scientific meaning and units. This implementation performs no unit conversion.

The writer uses the maintained OOXML helper and exact byte offsets for selected cells; it does not save the workbook through an object-model library. Every untouched worksheet cell and package member is retained byte-for-byte. The ZIP container itself is a newly generated derived file. Existing calculation flags request full recalculation when available; no formula, macro or external link executes here. Formula caches remain original until the recipient recalculates with the ordinary spreadsheet application. Recalculate and inspect the actual derived workbook before presenting calculated spreadsheet results. Original macros, drawings, styles and other sheets stay in the new file, without executing their content. Signed/encrypted/binary/template workbooks stay available as originals but are not edited.

Current supported sizes: original128MiB, expanded512MiB, at most2million physical cells per worksheet,100000mapped/excluded fields. Complete values are never shortened. An unsupported source gets an explicit source error rather than an approximate regenerated workbook.

## Original APIs

`profile_workbook_return.catalog(workspace)` returns saved profiles, workbook source parts and retained returns. `profile(workspace, profile_id)` returns complete native field values. `book(workspace, {source_collection_id,source_id,part,sha256?,profile_id?,sheet?,cell?,offset?,limit?})` returns original sheets, paged cells and explicit source-backed suggestions. `preview(workspace, selection)` returns eligibility, all mappings/changes/exclusions and exact preview_sha256. `create(workspace, selectionWithPreviewSha256, operation_id=originalTaskId, context=originalTaskContext)` retains the complete source-bound request and publishes once. `operation` resolves the original accepted request independently from current profile selection. `inspect` and `verify_all` read and verify prior originals without regenerating them.
