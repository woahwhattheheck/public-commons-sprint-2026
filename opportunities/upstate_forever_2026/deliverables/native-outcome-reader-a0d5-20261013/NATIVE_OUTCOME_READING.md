# Original native headwaters outcome reader

This companion reads the already-completed, explicitly simulated headwaters course. It does not execute InVEST, resummarize rasters, replace a scientific report, or select a new model case.

## Original course

The original producer selected a synthetic 1,296 ha square: 120 by 120 cells at 30 m, with identical model/report rectangles and zero buffer. Synthetic terrain, land cover, utility overlays and assumed coefficients remain declared. The case demonstrates actual native production and selected sensitivity; its location/CRS does not establish a completed Upper Savannah upstream-domain, South Carolina reporting-mask or utility study.

## Reading

- All native selections retains each original raster's annual sum, declared sum units, valid-cell count, source profile and run identity.
- Land-cover changes retains alternative minus baseline on the exact common valid cells, holding the profile fixed.
- Parameter sensitivity retains varied minus reference on the exact common valid cells, holding the scenario fixed.
- Descriptive ranges are the maintained producer's original groups. No subset range is recomputed. Exact mask SHA, quantity and units remain distinct. Same cell count alone does not identify the same geographic support.
- Recorded timings distinguish first completion/elapsed seconds from last reuse/continuation and completed visits. No invented total runtime is calculated.

Nitrogen and phosphorus retain kg/year; sediment retains the original metric-tonne annual units. The display permits the producer's equivalent metric_tonnes/year, metric_tons/year and tonnes/year aliases without numerically converting values. Load and intake concentration are different quantities.

Undefined percentage remains null when baseline is zero. The original JSON has the full numeric values; formatted tables show up to 12 significant digits. Scenario changes and parameter sensitivity are descriptive results of the selected inputs, not confidence intervals or evidence of independent calibration.

## Complete receiving and offline operation

The standard-library Node caller uses the complete exact packet and an explicit JSON-pointer bindings file:

```sh
node build-native-outcome-reading.mjs completed-native-consumer-packet.json native-outcome-bindings.json NEW_OUTPUT_DIRECTORY
```

The caller validates original packet bytes/SHA before building. It requires a new output directory and writes the complete original JSON, index.html, reading data, bindings and MANIFEST.json. It checks actual plan/run/profile/grid/scenario consistency and each comparison's original raster descriptors. Both maintained numeric release and original ensemble summary forms are supported. The values are copied from those producers.

Open index.html in a current browser. Choose the reading question, original parameter member, scenario and quantity. Inspect or export an original record; download the displayed rows or full reading data. Download complete original consumer packet decompresses and SHA-verifies the embedded unchanged bytes before saving. The HTML uses browser DecompressionStream and WebCrypto; no network request is required for its results/downloads. Original report/Workspace links are external retained downloads.

Native raster bodies and editable Workspace remain in the original producer's complete Study/history archives; the JSON download preserves their original descriptor records, not a replacement raster package. ## Original joint support-group reports

The maintained headwaters course separately retains `headwaters-results.json` with `joint_decisions.support_group_reports`. These are original Decisions reports using all-alternative finite-cell support, not the pairwise ensemble comparisons. To include them, add `paths.course` with its exact JSON pointer and `paths.joint_reports` with one pointer for each complete original support-group `report.json` in the same verified packet. Both must be present together. The adapter checks every report against its course descriptor, project, ensemble member, profile, native run order, grid, modeled quantities and exact support mask/members. It retains every original report and package descriptor. Comparison-artifact descriptors are kept in their original role; they are not relabeled as native raster descriptors.

The view shows original baseline and alternative common masses, `delta` (alternative minus baseline), `reduction` (baseline minus alternative), and original `reduction_percent`. It copies these values. It does not calculate new export totals, pool masks, or manufacture a restoration-versus-control contrast. Duplicate rows referenced by multiple original support-group reports appear once with every report ID; disagreements fail admission. Absent joint sources remain explicitly unavailable, while the original pairwise view remains usable.
