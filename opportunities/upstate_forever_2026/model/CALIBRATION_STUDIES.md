# Share and reopen an editable Calibration study

The Study transfer desk can capture an original Calibration design or evaluation directly. A recipient receives the selected scientific record, its original observations and geography, the native cases behind it, and the retained history needed to continue working in the same application.

## Choose the scientific record

From an open Calibration design or evaluation, **Share editable Study** opens the Study selector with that exact record selected. You can also open **Study transfer** and choose **Calibration designs** or **Calibration evaluations** in the type selector. The title and state identify the saved record. **Open Calibration design** opens the retained selection and progress; **Open Calibration evaluation** opens its original results.

Select the design or evaluation to include. Saved source-error reviews, residual maps, scientific reviews and Calibration report sources are additional explicit choices in the same selector. Their original dependencies travel with them.

Use **Preview contents** to inspect the original files and scientific records. Name the archive and choose **Export editable study**. The existing operation queue shows progress and the completed archive. **Transfer archive** uses the maintained transfer desk when the recipient needs multipart transfer. Keep the completed archive as a saved edition.

## Receive and read the result

Receive and restore the archive through the existing Workspace transfer controls. Open the restored Workspace, then **Study transfer → Received studies and original sources**.

The Calibration section displays the original observation edition, annual-record count, candidate native runs, distinct profiles, training groups and held-out groups. An evaluation with a selected profile displays its original physical error metrics separately for each constituent, unit and partition. Earlier evaluations remain in the selected-profile history.

- **Open original evaluation** returns to the original Calibration result, including physical history comparisons.
- **Open editable design** opens its retained sources, candidate selection, partitions and analysis progress. **Revise selection** creates the ordinary revised design.
- **Open selected native run** opens the original model case.
- The result and source downloads retain the captured files. Original records and methods remain available in the expandable source section.

An unfinished design keeps its original progress. The recipient can inspect and continue it using the existing analysis controls. A completed evaluation preserves the original result when it is opened or exported.

## Continue scientific work

The complete supported workflow starts with the user's original observation CSV and retained basin source. In Calibration, **Prepare gauge catchments** can delineate an additional source edition using the exact saved DEM. Choose the actual coordinate carrier, longitude and latitude columns, coordinate datum, vector layer and catchment ID field. Inspect original outlets and terrain before running native delineation. Review original and derived areas, outlet displacement, stream membership and DEM-edge support before interpreting full-catchment annual loads.

Prepare a Calibration selection from completed compatible native cases. Review original units, periods, objective terms and geographic groups; choose training and held-out assignments before fitting. **Analyze selection** performs the retained whole-catchment comparison and scoring. Result filters and original exports retain excluded and incomplete rows alongside the eligible result.

From a completed evaluation, **Continue selected profile** opens its exact native baseline in Parameter studies. Named working designs preserve unfinished fields, scientific notes, author attribution and revision history. Save the working revision, preview the scientific case design, then prepare and execute the chosen cases through the existing native queue.

Return completed cases to Calibration. The original observation edition, catchments and retained reference design remain available for review. The follow-up result links its earlier evaluation. Physical history compares unchanged original references and keeps changed support, changed partitions and incomplete rows visible. The new evaluation can be selected directly for another editable Study export.

## Scientific interpretation

The archive preserves source meaning; it does not change the evidential status of the inputs. Original measurements, published modeled annual references and illustrative model inputs retain their own descriptions and periods. Delineating a basin from a DEM does not change the provenance of the land-cover, soil, rainfall or coefficient inputs.

Physical error metrics retain each constituent's units. Kilograms per year of nutrients and tonnes per year of sediment are separate quantities. Training and held-out results remain separate. A new parameter choice informed by an earlier held-out result must be interpreted in that history.

An exported result is an original edition. New analysis progress and later exports do not silently add files to an older captured Study. The receiving view opens the retained design and original evaluation through the ordinary application controls.

## Integration and native operation

The feature extends the maintained Study closure and receiving reader. It uses the existing Calibration record visitor, original Workspace identities, source objects, native selections and producer export locks. The component is delivered with the Calibration installer and a maintained application component fragment.

Apply the complete current source cohort to an existing full application using the same installer:

```bash
python operator/install_calibration.py --application /absolute/path/to/application --source /absolute/path/to/upstate_forever_2026 --preview
python operator/install_calibration.py --application /absolute/path/to/application --source /absolute/path/to/upstate_forever_2026
```

The paths identify the actual receiving application and complete source checkout. The installer preserves concurrent source and records replaced versions through its existing history. Restart the receiving application through its ordinary launch command after source adoption.

Operate the complete original journey in the receiving application: open a saved Calibration design and completed evaluation; capture a selected Study; restore it into a new destination; open the readable received evaluation and its original native case; revise the retained selection; and reopen the saved result and downloads. View the desktop and narrow layouts with the actual populated scientific records.
