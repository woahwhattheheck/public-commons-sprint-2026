Operate and explain this handover

1 · Inspect the delivered study

Do: select a layer, inspect its units and identity, then use Fit selected layer.

See: its actual geographic footprint and source/run metadata.

Say: “Each layer identifies which source and case produced it, so we can trace the map back to the underlying data.”

2 · Work with the complete data

Do: open project.qgz in QGIS. Expand a case group, inspect raster cells or a vector attribute table.

See: full-resolution data and independently editable vector working copies.

Say: “This is an editable GIS project, not just a picture. Your operator receives the layers, units, source files and the project structure.”

3 · Save and transfer an edition

Do: save the QGIS project inside this directory, close editing, then run the included seal, pack and receive commands from the operating guide.

See: a new retained edition with the reason for the changes and a complete portable archive.

Say: “You can continue independently. We retain the original data and identify the changes in each transferred edition.”
