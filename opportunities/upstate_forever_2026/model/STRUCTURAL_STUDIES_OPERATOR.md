# Structural studies — operator and complete project receiving

## Open the original scientific project

Open **Structural studies** in the existing authenticated Upper Savannah operator. The desk uses the current scientific Workspace, its saved source collections, prepared grids, profiles and completed native runs. It does not create another scientific database or run service.

Start with a completed original reference run. The catalog shows the run's actual scenario, grid and profile identities. Open **Inspect original reference** to review its retained input and output records. A structural study preserves that reference scenario and biophysical table while documenting a specific change to model structure.

This is a comparison programme. The production designation remains at 30 m. The scientific plan and report retain the original methods, versions, source limitations and support definitions; a result is not an authorization to replace the production design.

## Choose the scientific question

| Family | Guided inputs | Scientific boundary |
| --- | --- | --- |

Choose one family for a study. Rainfall and R-source changes belong to the separate rainfall workflow. Changing an existing draft's family preserves its earlier fields for review; readiness identifies incompatible retained options. Use **Separate editable copy** when you need a new study with a different scientific basis, then make the intended changes explicitly.

Give the study a recognizable title and purpose. For each case, choose its original prepared grid, add a label, explain the scientific reason and retain the relevant source references. Routing and stream-definition cases use the reference grid. The grid panel shows original cell dimensions, cell area, size and coordinate system; the complete source record remains available in its disclosure.

A cross-grid comparison uses the original projected-meter coordinate system and the maintained exact rectangle-overlap implementation. Its allocation of cell mass within an intersected cell is explicitly a within-cell uniformity assumption. Review that assumption, shared support, exclusive coverage and the original output units in the saved plan and report. The desk performs no replacement interpolation or new model calculation.

## Reuse an original completed case

Each case offers **Reuse an original completed case (optional)**. This names an already completed producer run. The model validates its exact grid, scenario, selected models, effective parameters, physical stream area, full biophysical table, original source bindings and retained artifacts before adopting its existing run and profile IDs.

The menu helps locate a run with the same selected grid, scenario and model scope. Readiness performs the complete scientific comparison; the menu alone does not certify equivalence. A missing original run remains visible as a retained choice and must be recovered or changed explicitly.

Leave the choice blank to prepare a new original case. An accepted explicit reuse keeps the producer's real run and profile identities; it does not create a numerical duplicate merely to include that case in a study. The reference itself must already be complete.

## Working copies, interrupted replies and other tabs

**Download working copy** saves the complete visible selection, original project identity, frozen study association, original requests and received results. This file is useful for continuing the same scientific work. It does not contain the entire native dataset; receive the full project archive when moving source files and results.

**Open working copy** retains the unchanged original file and validates its full selection, study association and command history. A claimed completed command is checked against the real original journal before being treated as complete. Import does not dispatch another command automatically.

If a reply is interrupted, choose **Read original result**. The adapter resolves the original operator task or exact retained alias before reading the model journal. A queued task can exist before the model has created its intent; that is pending work, not a completed operation or permission to allocate another ID.

If the original request was never received, **Retry this exact request** uses its same UUID and entire saved body. If the original task is interrupted, use **Resume original task** after inspecting its actual status and logs. The original queue owns retry and cancellation. A canonical task ID can differ from the authored request UUID when the maintained queue retained an alias; both identities and the complete request remain in the working copy.

On a cold receiver, a known canonical task ID and its exact model origin can resolve the retained request. An unknown operator-only alias requires the original operator task/alias handoff. Do not infer completion or create a replacement request by searching for an equivalent payload.

Another tab cannot silently overwrite a working copy. Each complete body is saved with an atomic revision comparison. If storage or revision saving fails, the visible draft keeps its original comparison basis and survives a workspace remount in memory. Download it, save a separate copy, or explicitly reopen the other saved version. Returning to the same project does not silently advance the losing draft's expected revision.

### Changing a scientific basis

Changing the family or original reference retains the full prior selection in the working-copy history. Active case fields are adapted explicitly: routing controls include only the reference's actual models, and physical stream-area fields appear only for stream-definition studies. Fields that belong to a different family are removed from the active request and kept in that history. Routing defaults are visibly drawn from the selected reference; new stream areas remain blank until entered. Original completed-case reuse is cleared at this boundary and must be explicitly reselected and verified for the new basis.
