## Use the existing operator

Open a saved design in **Scenario sensitivity** and choose **Prepare scientific study report**, or open its completed calibration result and choose its existing scientific report action. The report form lists original evidence for the actual member profiles and their saved parent or profile-derivation chain. Select the desired evidence editions and, separately, any source ranges. Nothing is selected automatically on the first use. Reopening the same result retains that result's explicit source choices. ## Exact command-line operation

Use the existing equipped application and its original Workspace. Obtain choices from the saved native design:

```bash
python -m model.ensemble_consumers_cli --workspace "$WS" coefficient-evidence --ensemble-id "$ENSEMBLE_ID"
```

For a completed scientific calibration, use the same command with `--consumer-id "$CONSUMER_ID"` instead of `--ensemble-id`. Write the actual selected IDs into a JSON file, for example:

```json

```

Prepare the existing source and ordinary scientific report:

```bash
python -m model.ensemble_consumers_cli --workspace "$WS" study-source --ensemble-id "$ENSEMBLE_ID" --coefficient-evidence coefficient-selection.json
```

The corresponding calibration command is:

```bash
python -m model.ensemble_consumers_cli --workspace "$WS" scientific-source --consumer-id "$CONSUMER_ID" --coefficient-evidence coefficient-selection.json
```

The existing `--source-only` option prepares the complete registered source for the ordered composer. Omitting `--coefficient-evidence` preserves the original producer behavior; an explicit empty object selects a table-only evidence edition. Native models are not executed by these commands.

## What the evidence means

Each original evidence record keeps its original profile ID, table identity, source CSV, cell citations and load-type interpretation. A member receives documented input support only through its original profile or an explicit retained parent/derivation chain, with the same land-cover code, coefficient, numeric value, units and nutrient `load_type`. Coincidentally equal values in another lineage do not establish support.

The report shows each actual profile separately against each selected evidence edition. A changed value or load type is marked changed; an absent or unattributed cell remains unsupported. Counts from distinct evidence editions are never summed. These are coefficient-cell counts, not geographic coverage, statistical confidence, calibration performance or evidence that model outputs are correct. Native algorithm parameter sources and the original scientific interpretation stay with the existing report sections.

Selected ranges retain their original central/lower/upper profile records and coefficient sources. An actual member is labeled as an exact endpoint only when its profile ID matches that saved endpoint ID. A derived member with similar values can use unchanged cited cell inputs through its real lineage, but does not acquire an invented endpoint role. Lower/upper coefficients do not necessarily produce lower/upper pollution outcomes.

## Complete retained files and source identity

Every selected source recipe includes:

- `coefficient-evidence/ensemble-coefficient-evidence.json`: explicit selection, original cohort lineage, per-profile applicability, source and registry descriptors.
- `coefficient-evidence/member-coefficient-applicability.csv`: every actual profile/evidence/land-cover/coefficient comparison, including original and actual values, units, load type, relationship and status.
- `coefficient-evidence/selected-coefficient-evidence.csv`: the original selected source cells and cited range endpoints.
- `coefficient-evidence/coefficient-evidence.json`: the ordinary coefficient report's retained inventory.
- `coefficient-evidence/records/`, `sources/` and `implementation/`: exact original records, original CSV bodies and bound report source code.

The source operation identity includes the explicit selection, actual cohort, original evidence/range record digests, profile/table identities and exact implementation fingerprints. New evidence choices make a new source edition; old source editions remain readable. Interrupted preparation resumes the same edition. The calibration consumer's latest pointer selects the prepared evidence edition only while its original result IDs still match.

Study capture validates those original records and source bytes, recalculates cell applicability from the retained tables, preserves all selected range endpoint profiles and adds the original evidence/range records to the editable project. Foreign-project reports keep their original project identities in their captured source; they are not retagged as receiving-project evidence.
