Review a rainfall release

Load one capture to inspect coverage and rainfall totals. Load a second release for the same sensors and window to see changed values, source changes, recovered readings, and gaps.

Use the included capture command to retrieve the public rainfall result, or reopen a previously saved review project.

Files are processed in this browser. Saving a review includes the original responses and your notes. The reviewer makes no network requests.

Capture a public rainfall window

First use node capture.mjs bounds to check available dates, then node capture.mjs sensors to verify IDs.

Run node capture.mjs capture --start ISO_START --end ISO_END --sensors 1,2 --label "Historical release" --out release.json using explicit UTC or offset timestamps. See README for the full command and time-window rules.
