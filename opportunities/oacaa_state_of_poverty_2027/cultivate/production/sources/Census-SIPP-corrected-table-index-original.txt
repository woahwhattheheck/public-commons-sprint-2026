# Corrected Annual and Monthly SIPP Poverty Rates: 2014-2022

 February 2024 

These tables provide the original and updated annual and monthly poverty rates for the 2014-2022 Survey of Income and Program Participation (SIPP) following the implementation of a post-hoc Social Security Processing Error correction. More information about the impacts on poverty can be found in the user note titled [2022 SIPP: Social Security Processing Error and its Impact on Poverty Estimates](https://www.census.gov/programs-surveys/sipp/tech-documentation/user-notes/2022-usernotes/2022-soc-sec-proces-err-impct-pov-est.html). More information on the processing error can be found in the user note titled [2022 SIPP: Prior Processing Error Affecting Social Security ‘Self’ Amounts](https://www.census.gov/programs-surveys/sipp/tech-documentation/user-notes/2022-usernotes/2022-prior-process-err-affct-soc-sec-self-amts.html).

While these tables include the post-hoc correction to annual and monthly poverty rates, they were not calculated using the most recently released (July 24, 2025) Social Security fix data. To use these data and generate the most up to date estimates for SIPP 2014 Wave 1 through 2021, refer to [the SIPP datasets webpage](https://www.census.gov/programs-surveys/sipp/data/datasets.html)and select the tab for the year of interest.
