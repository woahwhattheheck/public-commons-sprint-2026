# Original formula library

The operator's Workbooks page contains the complete original formula library.
It joins the source owner's full five-workbook study to the retained native
calculations in this same questionnaire workspace. Select a workbook, sheet,
function, source cell or stable question ID; open a group and then a cell to
inspect its original expression, shared-formula expansion, original cache and
actual native outcome. The interface supports English and French and preserves
the current source selection when its language changes.

The received original family contains 7,661 formula occurrences across all
79 worksheets, including the 21 hidden worksheets. The source study expands
1,345 shared followers from 223 masters, retains 1,302 workbook-specific groups
and 904 structural shapes, and records 11,050 original reference tokens and
2,269 direct formula edges. All 7,661 occurrences are joined to their original
native engine token and calculated workbook records.

The original read-only source reader is retained unchanged as
`source_formula_reader.py`: 29,214 bytes, SHA256
`96b40d6251c4060aeb752b2435f9f03a28333f86366b25380a8d641af1be2ae5`.
Its source-owner carrier is Canvas `F0C88E49SMD`; the complete original archive
is retained under `workspace/source-evidence` with SHA256
`f31ec3fef4ee808ada65afb66cfbf67114c7be8016ca6307bf664c56bffcab8e`.
`source-authority.json` retains that source relationship with the joined edition.

## Open the existing customer project

Start the received application with its retained workspace, then open Workbooks:

```sh
python3 application/server.py --workspace ./workspace
```

Use the operator access code retained in `workspace/operator-key.txt`. The
already received collection contains all original source groups and native
joins. **Receive original formula groups** also imports the whole original
family through the ordinary native application. **Refresh original source join**
retains a new collection when the original definition or native source edition
changes. Previous collection identities remain available to the native API.

Group pages show functions, physical source members, original reference-error
members, native error members and bound stable question IDs. Cell inspection
shows full original formula attributes, effective shared expression, static
tokens and references, and actual native ranges/error codes. It retains the
original source cache separately from the recalculated original workbook.

The native join also resolves referenced declared inputs to their exact stable
question, table column and physical worksheet row. Searching the C36 production
question `s_649106f345_5f56359e_c36_i36` finds the eight original groups that
consume it, including the C38 total group. The C38 cell retains the exact C36
`c_c` binding and the published flattened native dependency IDs. A source table
with gaps retains those original rows rather than attributing values to its
intervening rows. Whole-group search includes the original output and referenced
question IDs, source reference cells and representative original expressions.

The native-edition selector opens any completed calculation tied to that same
original workbook. It uses the existing retained source, answered and calculated
SHA bindings. For example, the foreign-producer C38 production formula returns
150 in the entered edition, and 30 in both the zero and cleared editions. Their
different original inputs and workbook identities remain retained. Existing
respondent errors, public masks and accepted revision history keep their original
native records.

The locked manifest records their original download URLs, byte counts and
hashes. The complete wheels retain their upstream licenses. Analysis validates
those bytes and starts Python with `-S`, loading only the shipped wheels and
the standard library. The existing six-wheel document environment stays the
document runtime. No package installation or network request is needed to open
or rebuild this source library.

Whole-project export and receive retain the SQLite collection, original archive,
all source study files, joined source/native files, reader output and diagnostics,
the original reader code and both runtime wheels. A completed analysis is reused
only after checking its full file inventory. An interrupted source analysis is
retained under its original attempt and resumes through a fresh complete attempt.
The application uses a filesystem lease and a short final SQLite write, so source
analysis leaves the native response writer available.

Run the complete repeatable source programme through the same application:

```sh

```

Its retained `source-evidence/formula-library/complete-programme.json` indexes
the original/native whole-family join, all original group coverage, real selected
native C38 editions, exact receiving replay and independent process reopening.
The same programme verifies that questionnaire, publication, respondent,

## Native API

Use the normal `cli.py ... invoke` command or the operator's authenticated API:

| Method | Parameters | Result |
| --- | --- | --- |
| `source_formula_import` | Stable `request_id` | Complete source collection, native joins and full pinned file inventory |
| `source_formula_inspect` | Optional `collection_id` | Collection totals, five source workbooks, retained native jobs and collection history |
| `source_formula_groups` | `collection_id`, optional `workbook_sha256`, `worksheet`, `search`, `offset`, `limit` | Complete filtered group count and an ordered page of up to 100 groups |
| `source_formula_group` | `collection_id`, `group_key` | Original normalized group and every complete source/native member |
| `source_formula_cell` | `collection_id`, `source_key`, optional `calculation_id` | Original source record and the selected actual native edition |

Source analysis preserves anchored and relative reference axes, worksheet spans,
resolvable defined names, raw errors, hidden-sheet origins and unresolved source
cases. Structural groups help an operator find repeated original logic. Native
formula tokens and the complete LibreOffice calculation supply the actual
computed outcomes and response disclosure lineage. The source study's visible
dependency reachability retains the source owner's conservative interpretation;
hidden FY, Variables and INT/report origins remain explicit source members.

The underlying parser's source contracts are documented in the official
[formula tokenizer and translator guide](https://openpyxl.readthedocs.io/en/stable/formula.html)
and [read-only workbook reader API](https://openpyxl.readthedocs.io/en/stable/api/openpyxl.reader.excel.html).
The original native calculation/runtime and complete original-cell compiler
are documented in [NATIVE_CALCULATION.md](NATIVE_CALCULATION.md).
