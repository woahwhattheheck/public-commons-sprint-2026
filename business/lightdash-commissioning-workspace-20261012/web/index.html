Portable receiving package
The package uses a consistent SQLite backup and preserves complete file contents. The receiving copy starts with its host connection detached. Configure the receiving host explicitly before another native operation.
Host-bound private profiles, API keys and the Lightdash user configuration are excluded. Native content can contain customer data; choose the intended receiving location.


Receiving sequence
  1. Extract the complete package into a new directory.
  2. Open its local workspace using the included Node application.
  3. Review the retained source, native content and original operation results.
  4. Configure the actual receiving runtime, host profile and Lightdash project.
  5. Prepare a new operation against the selected retained edition when ready to continue.
