KZFR Editorial Bridge: source-first companion plugin for an independent KZFR buyer proof.
Adds WordPress REST-enabled Programs/Genres, Community Events, and Underwriters.
Program media URL metadata is restricted to HTTPS kzfr.studio.creek.org links.
No polling, fetching, streaming, scheduled jobs, payment logic or user data handling.
Activate plugin before activating the theme. See bundle README.md for limitations.
