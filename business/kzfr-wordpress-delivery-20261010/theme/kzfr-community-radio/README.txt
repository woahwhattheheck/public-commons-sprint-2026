North State Signal: independent WordPress theme candidate, not an official KZFR release.
Requires WordPress 6.3+, PHP 8.0+, and the Twenty Twenty-One core parent theme. Install the companion kzfr-editorial-bridge
plugin to supply the Programs, Community Events and Underwriters content model.
This theme links to Creek Studio for real audio: it does not replace station services.
See the bundle README.md for the original KZFR RFP, scope gates and acceptance work.

Station staff with edit_theme_options can open Appearance > Customize > Station service links
to change Listen live, Audio archives, Program schedule and Donate destinations. Clearing
a field hides that service link. Only the listed station/Creek HTTPS hosts are accepted.
Program Creek links, community event dates and underwriter websites come from the companion
plugin's existing content fields. See THEME_INTEGRATION.md for source defaults and handoff.
