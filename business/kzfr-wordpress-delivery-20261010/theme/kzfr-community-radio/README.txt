North State Signal: independent WordPress theme candidate, not an official KZFR release.
Requires WordPress 6.3+ and PHP 8.0+. Install the companion kzfr-editorial-bridge
plugin to supply the Programs, Community Events and Underwriters content model.
This theme links to Creek Studio for real audio: it does not replace station services.
See the bundle README.md for the original KZFR RFP, scope gates and acceptance work.
