# Ready-to-open CMDB acceptance applications

Download either HTML file, keep its `.html` extension, and open the saved file in your browser. Each file includes the application, complete operating guide and editable source.

- **Open_CMDB_Workspace.html** starts with an empty workspace for your authorized exports.
- **Worked_Hardware_Acceptance.html** opens the complete authored hardware example, including four original CSV editions, correction history, exception decisions and receiving record.

Use **Download complete handover** from the application to carry the selected workspace, original inputs, report, exception CSV and complete source together. Use **Save private workspace** regularly to keep a separate editable copy. Store real customer exports and handovers in the location selected by their authorized custodian.

The **Operating guide** link in the footer is available before you create a workspace. The browser retains completed work in its local storage. Opening a different browser profile or moving to a receiving operator is handled by the full workspace or handover download. The included operator guide describes the complete intake, correction and receiving workflow.
