# CMDB acceptance and correction workshare

## Prepared for Alcor

**Fixed fee: $3,600. Delivery: ten business days from an agreed start and complete authorized inputs.**

We can take the export reconciliation and receiving record for one agreed CMDB class or asset scope through delivery. Alcor retains the ServiceNow engagement, platform operations and customer relationship. We provide the selected source/target comparison, exception ownership record, corrected-target rerun and complete portable acceptance package.

This is a concrete specialist work package alongside your existing quality and CMDB services. The supplied application works from complete authorized CSV exports and keeps the receiving record editable by your team.

## Included work

1. **Agree and record the data scope.** Confirm the CMDB class or coherent asset cohort, extraction dates and filters, stable record key, compared fields and receiving reviewer.
2. **Receive the original exports.** Retain the baseline, first target and each correction as complete file editions. Identify missing columns, malformed rows and blank or duplicate keys before the comparison.
3. **Prepare the exception register.** Compare the selected source and target using the explicit field mapping. Review the results with named owners, correction actions and accepted changes linked to a written reference.
4. **Operate one corrected-target rerun.** Keep the original comparison, link the corrected target to the received edition, and carry only identical accepted findings when the reviewer selects that behavior.
5. **Deliver the receiving record.** Assemble the readable acceptance report, exception CSV, original audit, complete editable workspace, all original inputs, operating guide and self-contained application. Reopen the delivered package and confirm that the same decisions and source editions are present.

The fixed scope includes one baseline, one first target, one corrected target, one agreed mapping and one receiving review cycle. Each original CSV may contain up to 100,000 records and 16 MiB. A larger export, additional class or changed matching/transformation requirement is scoped separately before that work starts.

## Your team's inputs

Supply the authorized baseline and target exports through your selected private route, identify the stable cross-system record key, select the acceptance fields, and name the receiving reviewer. Your team retains the instance access and customer approvals. We use the complete files within the agreed scope and return the full working record.
